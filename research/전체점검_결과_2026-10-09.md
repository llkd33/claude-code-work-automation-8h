# 8H 과정 전체 점검 결과

대상: Claude Code 업무자동화 8H의 최신 개인 실습 과정. 2026-10-09. SK Gas 자료는 이번 변경에 포함하지 않았다.

## 평가와 반영

아웃풋과 재사용 흐름은 분명하다. 체크리스트→같은 비용표의 보고서→환율 API→Skill→다음 주 입력→파일 변경 자동화를 끝까지 연결한다. 쉬운 첫 성공과 눈에 보이는 변화가 있지만, 재미나 초보자 완주율은 아직 측정하지 않았다.

| 발견 | 반영 |
| --- | --- |
| 제작 포인터에v3 범위 잔재 | project.md를 현재 개인 실습 v6로 수정 |
| 읽기용 표/폼/퀴즈 라벨이 붙음 | 실제 Markdown 표·체크·퀴즈보기로 재생성. 동적 폼은 10칸 작성 템플릿으로 안내 |
| Google 부록이 필수 M2를 전제 | 선택 심화의 선행 조건으로 변경하고 필수 환율 흐름과 일치 |
| Skill 이름·설명 예시 누락 | name·description·명시호출 설정 예시 추가. 실제 파일에서 찾도록 안내 |
| 개인 실습이 도움 금지로 읽힘 | 강사에게 질문하고 받은 도움을 기록하는 개인실습 안내로 수정 |
| 최종 visual_docs 생성기 누락 | 파일 복구 후 실제 build/release 실행 |

추가로 10칸 계획은 ‘누가 쓰는가/무엇을 넣는가/무엇이 나오면 끝인가’부터 시작한다. 보고서 숫자는 유지하면서 공유 초안의 받는 사람과 요청 행동은 직접 바꾼다. JSON은 항목 이름 옆에 값을 적은 데이터 메모로 설명한다. Playwright/E2E는 마지막 제출 단계에서 소개만 하며 폐쇄망 설치와 사람 확인을 안내한다.

## 유지한 범위

개인 활동 21개·휴식 4개·운영 480분=활동 440분+휴식 40분, 필수 API 35분·자동 감시 40분, A1–A6 목표를 유지한다. 새 DB·상담봇·배포를 필수 과제로 더 넣지 않았다. 계산/API/감시 도구와 원본 Excel은 보존한다.

## 윤문·검증 증거

사용자가 지정한 im-not-ai의 humanize-korean 스킬을 실제 적용했다. _workspace/2026-10-09-001-31cc에 현재 설명 650구간의 원문·진단·16개 청크·재조립·의미검수·게이트를 보관한다. 최종 변경률·판정은 _workspace/review-humanize-verification.json을 기준으로 읽는다. 첫 윤문 기록은 덮어쓰지 않는다.

전체 배포 검증 로그: _workspace/review-20261009/release-final-complete.log. 명령·코드·원본 해시·문서의 fenced code·실제 제공 도구 검사·추출ZIP 실행과 최신 바이트를 확인한다. 독립감사는 같은 폴더의 전체점검_독립감사.md에 기록한다.

## 시각화와 촬영

개념 도식 9개의 PIL 프리뷰를 직접 열어 숫자·분기·글자·실습 순서를 확인했다. HTML에는 기존 7개 이미지와 새 9개 SVG를 실제 삽입했다. PIL 프리뷰는 브라우저에서SVG를 렌더한 결과가 아니다. 실제 제품 화면 촬영 목록은 [촬영 안내](전체점검_촬영안내_2026-10-09.md)에 있다.

현재 환경의 Chrome 실행은 실패해 실제 교안의 화면·복사·다운로드·모바일 동작을 확인하지 못했다. 실제 API 연결·교육장의 새 환경 설치·Windows/macOS인증·Claude 첫 제작/Skill 실제 호출·Google계정도 별도 리허설 사항이다. 주입된 API 응답·DEMO·제공 코드 검사를 실환경 성공으로 세지 않는다.

## 다음 리허설

초심자 3–5명의 개인 실습에서 첫 작동 시각·창/폴더 혼동·도움 횟수·추가 AI 요청·개인 변화의 반영·카드만 보고 다음 주 재실행을 기록한다. 재미있던 장면과 막힌 단계를 하나씩 묻고, 관찰된 시간에 맞춰 10칸 계획과 A/B 터미널 안내를 다시 조정한다.

## 최종 판정

독립 과정 검수 2회에서 발견한 결함을 모두 수정했다. 열린 확정 결함은 0건이다. 최종 release.py 통과: 로컬 33·API 26·watch 12개 핵심 검사와 양 ZIP 추출 실행·준비 확인·40/41/12건 결과 대조. 읽기용 링크 98개와 HTML 대상 번호도 확인했다.

윤문은 heavy 경로, 최종 게이트 exit 0·변경률 0.48%·등급 B·자체검증 6/6이다. 설명 650구간을 검토하고 52구간을 실제 반영했다. 의미 검수 중 조건이 바뀐 두 곳을 복구했다. 명령 상자 49개, 실행 파일 10개, 원본 Excel 5개와 문서 코드 블록을 보존했다. 옛 v3 제작 포인터의 띄어쓰기 수정 1건은 채택하지 않고 현재 v6 포인터로 교체했다. 이 판단은 run/superseded-edits.json에 보존한다.

과거 윤문 검사가 이번에 바뀐 문장을 옛 문장과 대조해 한 번 실패했다. 실제 2차 윤문 전 문서 스냅샷을 과거 단계 검사에 연결하고, 현재 원문은 별도 보호 검사로 확인했다. release-final.log의 실패와 이후 통과 로그를 모두 보관했다.
