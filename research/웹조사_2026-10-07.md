# Claude Code 업무 도구 만들기 · 웹 조사와 교안 결정

확인일: 2026-10-07. 범위: 비개발자 8시간 수업, Claude Sonnet 5.5, 설치·업무 자동화·CLAUDE.md·MCP·토큰 절약. 웹 검색으로 후보를 찾고 공식 문서 및 서버 제작자의 저장소로 교차 확인했다. 검색 결과의 요약과 커뮤니티 게시글은 설치 명령의 근거로 채택하지 않았다. 아래는 원문 복제가 아닌 교육용 요약과 설계 판단이다.

## 1. 핵심 결론

1. **Sonnet 5.5를 실제 모델명으로 사용한다.** Anthropic의 2026-09-28 출시 안내와 Claude Code 모델 문서를 확인했다. 모델 ID는 `claude-sonnet-5-5`. 기본 노력 수준은 Medium이다. 작은 수정은 Low, 오류의 원인 조사와 예외 검증은 High를 선택하는 수업 운영을 제안한다. [출시 안내](https://www.anthropic.com/claude-sonnet-5-5), [모델 설정](https://code.claude.com/docs/en/model-config)
2. **3단계 설치는 유지하되 역할을 수정한다.** Node.js는 데이터 스크립트와 npx MCP 실행용이다. Claude Code 자체는 네이티브 설치를 공식 권장 경로로 설명한다. Node가 Claude 설치의 필수 조건이라는 설명은 넣지 않는다. [설치](https://code.claude.com/docs/en/setup), [Node 다운로드](https://nodejs.org/en/download)
3. **Claude Code 사용 계정과 모델 이용 가능성을 사전에 확인한다.** 무료 Claude 채팅 계정만으로 Claude Code가 준비됐다고 판단하면 안 된다. 구독·조직 계정·Console/API 등 운영 방식은 주최자가 정하고 실응답까지 확인해야 한다. [인증](https://code.claude.com/docs/en/authentication), [빠른 시작](https://code.claude.com/docs/en/quickstart)
4. **토큰 절약의 중심은 재사용 가능한 코드와 좁은 입력이다.** AI는 만들기·고치기에 사용하고, 검증한 스크립트는 터미널에서 실행한다. 이 스크립트에 LLM/API 호출이 없다면 실행 자체에는 모델 토큰이 발생하지 않는다. 전체 원문을 대화에 붙여 넣는 실습보다 헤더·일부 행·집계 결과를 보는 실습을 우선한다. [사용량 관리](https://code.claude.com/docs/en/costs), [권장 작업법](https://code.claude.com/docs/en/best-practices)
5. **CLAUDE.md는 짧고 검증할 수 있는 규칙으로 작성한다.** 프로젝트 루트에 두고 `/context`로 로드 여부를 확인한다. 보안 통제 자체로 간주하지 않는다. 이번 수업의 20줄 안팎 템플릿은 교육 설계이며 제품의 제한값이 아니다. [메모리](https://code.claude.com/docs/en/memory), [권한](https://code.claude.com/docs/en/permissions)
6. **MCP 연결 성공을 설정 파일 생성과 구별한다.** 등록→승인→상태 확인→실제 도구 호출을 모두 확인한다. 기본은 파일시스템 1개. 웹 검색은 주최자가 Brave 키와 네트워크를 준비한 경우 선택한다. [Claude MCP](https://code.claude.com/docs/en/mcp), [Filesystem 제작자](https://github.com/modelcontextprotocol/servers/tree/main/src/filesystem), [Brave 제작자](https://github.com/brave/brave-search-mcp-server)
7. **Rewind는 파일 백업과 별개로 가르친다.** Claude 편집 도구의 변경은 되돌릴 수 있지만 쉘 실행으로 바뀐 파일과 외부 동작까지 복구하는 것은 아니다. CSV 원본·출력·백업을 구분한다. [체크포인트](https://code.claude.com/docs/en/checkpointing)

## 3. 토큰을 아끼는 수업 운영안

아래는 문서의 기능을 조합한 **교육 설계 판단**이다. 실제 절약률은 아직 측정하지 않았으며 일정한 비율로 줄어든다고 약속하지 않는다.

- 핵심 실습은 단일 세션·Sonnet 5.5·Medium. 작은 문구 수정만 Low로 낮추고, 2회 실패하면 짧은 오류 기록을 갖고 원인을 다시 조사한다.
- 요청할 때 입력 경로, 고칠 파일, 기대 출력, 제외할 범위, 확인 방법을 함께 준다.
- CSV는 헤더와 일부 행으로 구조를 확인하고 전체 처리는 스크립트에 맡긴다. 코드 전체와 모든 출력 행을 대화에 다시 출력하지 않는다.
- 외부 라이브러리가 필요한 경우에만 설치한다. 기본 CSV 실습은 Node 표준 라이브러리로 가능하고 Excel은 CSV UTF-8로 내보낸다. `.xlsx` 직접 처리는 선택 확장이다.
- 동일한 작업의 수정은 현재 세션에서 유지한다. 관련 없는 작업으로 전환할 때만 요약 파일을 남기고 `/clear`한다. 진행 중 문제가 복잡해졌다면 `/compact`로 필요한 조건을 보존한다.
- MCP는 필요한 서버만 연결한다. 최신 도구 탐색은 정의를 지연 로드하지만 서버 설명·이름·호출 결과·대화 자체는 여전히 맥락을 차지한다. 사설 게이트웨이는 동작이 다를 수 있으므로 `/context`를 보고 판단한다.
- `/usage`와 `/context`는 다른 지표다. 사용량/비용과 현재 맥락 점유율을 같은 숫자로 비교하지 않는다. API의 실제 청구는 Console에서, 구독 한도는 플랜 사용량 화면에서 확인한다.
- 결과물의 정확도를 위해 원본 행 수, 제외 사유, 부서별 합계, 총합을 확인한다. 토큰을 줄이느라 검증을 없애지 않는다.

## 4. MCP 실습에서 빠지기 쉬운 조건

- Filesystem MCP는 read/write 기능이 있다. 단순히 연결했다는 이유로 읽기 전용이 되지 않는다. 규칙 파일의 금지 문구도 강제 접근 통제가 아니다.
- 제작자 문서에 따르면 client roots가 전달되면 서버의 허용 디렉터리를 대체한다. Claude Code는 실행 디렉터리와 추가 작업 디렉터리를 roots로 전달한다. 따라서 `input/`만 인자로 주면 모든 다른 경로가 차단된다고 수업에서 주장하지 않는다. **실습 폴더 전체 루트에서 실행하고 홈/업무 드라이브를 추가하지 않는 학습 구성**으로 한다.
- `.mcp.json`은 Claude Code 프로젝트용이다. Claude Desktop의 `claude_desktop_config.json`, VS Code 자체의 `.vscode/mcp.json`과 구분한다.
- Windows npx stdio는 제작자 예시처럼 `cmd /c npx ...` 경로를 제공한다.
- Brave는 서버 제작자의 `@brave/brave-search-mcp-server`를 사용한다. stdio 클라이언트에 HTTP 실행 옵션을 잘못 붙이지 않는다. API 키는 대화·공유 템플릿에 실값을 넣지 않는다.
- Brave 선택 실습은 환경 변수 준비가 선행된다. 배포 설정 예시는 `${BRAVE_API_KEY}` 참조이고, 운영자가 해당 변수를 주입한 터미널에서 Claude를 새로 실행한다. 구체적 키 배포 방식·검색 요금·회사망 통과는 주최자가 확인한다.
- 연결 실패 시 성공으로 체크하지 않는다. 기본 파일 도구로 CSV 실습을 진행할 수 있지만 그것을 MCP 호출 성공이라고 기록하지 않는다.
