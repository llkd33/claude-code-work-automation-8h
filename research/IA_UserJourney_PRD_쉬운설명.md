# IA · User Journey · PRD의 쉬운 설명

2026-10-07 확인. 정의는 아래 원문을 참고했고 회의 준비 비유와 10칸 양식은 수업을 위한 자체 예시입니다.

## IA · 서랍 지도

정보와 기능을 찾기 쉽게 묶고 이름과 관계를 정합니다. 메뉴는 이 구조에 접근하는 화면 요소입니다. 첫 도구는 소개·입력·결과라는 정보 묶음 3개로 줄여 봅니다. 색상이나 버튼 배치가 IA 전체인 것은 아닙니다.
근거: [NN/g · IA와 내비게이션의 차이](https://www.nngroup.com/articles/ia-vs-navigation/)

## User Journey · 사람의 사용 이야기

특정 사람이 목적을 이루는 과정입니다. 상황·기대·행동뿐 아니라 생각과 마음도 함께 봅니다. 첫 도구는 “회의 직전 걱정 → 준비물 입력과 체크 → 남은 것 확인 후 안심”의 3단계로 줄입니다. 이 예시는 예상 사용 시나리오이며 사용자 조사 결과가 아닙니다.
근거: [NN/g · Journey Mapping 101](https://www.nngroup.com/articles/journey-mapping-101/)

## PRD · 만들기 약속

무엇을 누구를 위해 어떤 목적과 기능으로 만들지 팀이 이해할 수 있게 적는 문서입니다. 수업에서는 도구 이름·사용자와 문제·기능 최대3개·직접 확인할 방법으로 줄입니다. 정식 프로젝트의 전체 PRD를 대체하는 규격은 아닙니다.
근거: [Atlassian · PRD 작성 안내](https://www.atlassian.com/agile/product-management/requirements/)

## 이번 실습

예시를 읽고 빈칸10개를 내가 직접 채웁니다. AI는 계획을 대신 작성하지 않습니다. 짝이 빈틈을 읽고 본인이 고친 뒤, 완성 계획과 구현 요청을 함께 Claude Code에 복사해 index.html 한 장을 만듭니다.
