# 작은 팀과 로그인 앱 · v7 변경 근거

팀을 선택 시연에서 개인 정규35분으로, 환율API는 선택 참고로 옮겼습니다. 앱25분을 위해 혼자 재실행15→10, 확장시연10→앱, 결과 정리30→20으로 조정했습니다. 전체480분은 그대로입니다.

## 짧은 제작 요청

```text
엑셀을 넣고 실행하면 분석 보고서가 나오는 로컬 프로그램을 만들고 싶어. API 키 없이 이 PC에 로그인된 Claude Code를 써줘. integrations/auth-report/task-spec.md와 제공 소스로 준비하고, Windows에서는 ExcelReport.exe를 만들어줘. 실제 분석은 내가 실행기를 열어서 할게.
```

이 요청은 제공 명세와 실행 도구를 사용합니다. 인증 파일을 읽거나 배포하지 않습니다. 실제 분석은 학생의 실행 버튼에서 수행합니다. exe는 Node와 설치된 Claude CLI를 호출하는 실행기이며 단독 배포 앱이 아닙니다.

[공식 CLI 자동 실행](https://code.claude.com/docs/en/headless) · [인증](https://code.claude.com/docs/en/authentication) · [서브에이전트](https://code.claude.com/docs/en/sub-agents). bare 옵션은 OAuth를 사용하지 않으므로 이 실습에 쓰지 않습니다.

과거 윤문 검증은 생성 중 실제 v6단계 snapshot 대상으로 유지합니다. 새 v7의 말투·시간·경로·실습 내용은 현재 구조 검사와 독립 검수 대상으로 별도 확인합니다.
