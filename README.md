## 수정과 배포

웹 표시 파일은 실습핸드북.html입니다. 교안.md, course-source JSON, 관련 TXT와 내려받는 ZIP도 함께 맞춥니다. main에 반영하면 GitHub Pages가 자동 배포됩니다.

HTML의 section id와 data-note 키는 유지합니다. 입력한 메모는 같은 기기·브라우저·사이트에서만 저장됩니다.

수정 전 전체 파일은 실습핸드북_수정전.html에 보관했습니다. 연구 자료는 당시 설계 참고 기록입니다.
