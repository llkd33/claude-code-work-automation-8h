## ChatGPT와 함께 수정하기

이 저장소를 GitHub 연결에서 선택하고 수정할 챕터나 문장을 알려 줍니다. 현재 웹에 표시되는 파일은 `실습핸드북.html`입니다. `교안.md`는 읽기용 문서이고 `course-source/`는 챕터·요청별 참고 데이터입니다. MD나 JSON만 바꾸면 웹 내용이 바뀌지 않으므로 HTML도 함께 수정해야 합니다.

- 본문·설명 수정: `실습핸드북.html`과 `교안.md`를 함께 수정합니다.
- 실습 요청 수정: 관련 TXT·실습 가이드·`course-source/prompts.json`까지 같은 내용으로 맞춥니다.
- 자료를 수정했으면 관련 내려받기 ZIP도 새로 묶습니다.
- 페이지의 입력은 같은 기기·브라우저의 로컬 저장소에 보관되며 다른 기기와 동기화되지 않습니다.

# Claude Code 업무 자동화 · 개인 v8

총 8H, 오전 3H는 설명과 강사 시연, 오후 5H는 개인 실습입니다. 신청서의 기존 모듈별 시간과 첫 제작 위치는 참고 기록이며, 현재 진행은 이 구성으로 합니다. 단계별 분·시각 안내는 사용하지 않습니다.

| 구간 | 진행 | 결과 |
| --- | --- | --- |
| 오전 3H · Module 1 | 개념 설명·강사 시연 | 터미널·의도·스펙·프롬프트·에이전트 이해 |
| 오후 · Module 2 | 첫 제작·스킬 창작·업무 자동화 | 체크리스트·회의록 스킬·회의록 2개·내 업무 실행기 |
| 오후 · Module 3 | 나만의 재사용 환경 | 규칙·보고서 스킬·3명 팀·실행기·감시·Gmail 초안 |

오전 카운터는 강사 시연이며 학생 과제로 추가하지 않습니다. 짧은 직접 요청 뒤 로컬 MD 스펙을 @로 지정해 계획·확인·구현·검사를 비교합니다. Spec Kit 설치와 학생 웹 검색은 진행하지 않습니다.

오후에는 운영진 제공 계정과 바탕화면에 푼 실습 자료로 준비합니다. 첫 체크리스트 → 회의록 스킬 직접 작성·인터뷰·적용 → grill-me → 비용 보고서·내 스크립트 → CLAUDE.md·보고서 스킬·정규 3명 팀 → 재사용·로그인 실행기·자동 갱신 → Gmail 초안 순서입니다.

한빛화학은 완전한 가상 회사입니다. 외부·내부 미팅 원메모와 제품·보고 기준을 제공합니다. 원문에 없는 결정·담당·마감은 미정으로 남깁니다. 회의의 제안 금액을 확정 매출이나 비용 데이터와 합치지 않습니다.

## 화면 메모와 복사

짧은 메모와 짧은 요청의 빈칸은 핸드북 화면에서 적고 복사합니다. 같은 브라우저·같은 사이트 주소에서는 입력이 로컬 저장소에 남습니다. IP로 저장하지 않으며, 다른 기기·브라우저에서는 이어지지 않습니다. 브라우저 저장을 지우거나 비공개 창을 닫으면 메모가 사라질 수 있습니다. 복사 권한이 막히면 선택된 글을 Ctrl+C 또는 ⌘C로 복사합니다. 긴 설치 내용과 준비자료는 TXT·MD 파일을 사용합니다.


## 실제 결과를 바꾸는 연결 실습

- 첫 웹페이지 다음:가상 고객 5명으로 로컬 고객관리 앱을 만듭니다. 한 명 추가→회사명 검색→상담 상태 변경→닫았다 열기→메모 칸 하나 추가를 직접 합니다. output/customer-app/index.html, 같은 브라우저·같은 로컬 주소의 저장을 확인합니다.
- 비용 보고 다음:사실 CSV·보고 기준·지난주 보고서·이번 주 메모 4개로 팀장 보고·대시보드·팀 공유문·메일 초안·차트 데이터 5개를 만듭니다. 41건·2,363,300원·전주30,000원 증가를 대조하고 보고서 한 부분만 수정합니다.
- CLAUDE.md 다음:상담 규칙 한 줄을 직접 쓰고 FAQ로 답변 초안 3개를 만듭니다. 자료에 있음·자료에 없음·비교 질문을 확인합니다. 별도API 챗봇이나24시간 서비스는 만들지 않습니다.
- 팀 결과 다음:같은 41건으로 “진행 중 비용을 먼저” 한 줄만 바꿔 처음과 새 화면을 비교합니다. 정의는 그대로이며 실제 3명 호출과 숫자 불변을 확인합니다.

학생은 복잡한 node·PowerShell 빌드·인증상태 검사 명령을 직접 입력하지 않습니다. Claude에게 제공 도구 실행을 자연어로 맡깁니다. 실행·인터뷰·새 연결 실습·팀 재실행도 사용량이 듭니다. 완성된 실행 파일을 누르거나 감시 입력 파일을 교체할 때는 별도 제작 요청을 보내지 않습니다. 각 수정은 한 부분에만 한정합니다.
