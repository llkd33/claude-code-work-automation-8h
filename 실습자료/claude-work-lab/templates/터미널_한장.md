# PowerShell·터미널 한 장

터미널은 글자로 프로그램을 켜는 창입니다.

## 1. 창 열고 실습 폴더로 이동

- Windows: 시작 메뉴에서 PowerShell을 찾습니다.
- Mac: Command + Space를 누르고 터미널을 찾습니다.
- 실습자료.zip을 풀고, workbooks·templates·integrations가 든 claude-work-lab 폴더를 찾습니다.
- Windows는 폴더 우클릭 → 경로로 복사. Mac은 폴더 선택 → Command + Option + C.
- 핸드북의 cd 명령에 복사한 경로를 넣습니다. 큰따옴표는 양끝에 한 쌍만 둡니다.

## 2. 로그인하고 켜기

Claude Code를 아직 설치하지 않았다면 핸드북의 설치 안내부터 진행합니다.

```text
claude auth login
```

열린 브라우저에서 수업 계정으로 로그인합니다. 완료되면 같은 터미널에서 켭니다.

```text
claude
```

Claude Code 안에서는 한국어 프롬프트를 입력합니다. `/model`은 모델 선택, `/login`은 다시 로그인할 때 씁니다.

## 3. 다시 켜기

Claude 안에서 `/exit` → 같은 터미널에서 `claude`를 입력합니다. 새 창을 열었다면 먼저 실습 폴더로 이동합니다.

## 필요할 때만 쓰는 명령

- `pwd`: 지금 있는 폴더 보기
- `ls`: 파일과 폴더 목록 보기
- `mkdir terminal-practice`: 연습 폴더 만들기
- `cd terminal-practice`: 그 폴더로 이동
- `cd ..`: 한 단계 위로 이동

명령 연습은 새 터미널 창에서 합니다. 계산이나 자동 갱신은 열린 Claude Code에 프롬프트로 맡깁니다.
