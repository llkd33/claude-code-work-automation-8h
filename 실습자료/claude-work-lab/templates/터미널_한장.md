# PowerShell·터미널 한 장

Windows: 시작 메뉴 → PowerShell 검색 → 실행.
macOS: Command + Space → 터미널 검색 → Enter.

## 기본 명령 · 강사 시연 뒤 오후에 직접 연습

- pwd: 지금 있는 폴더 경로 보기.
- ls: 그 폴더의 파일과 폴더 목록 보기.
- mkdir terminal-practice: 빈 연습 폴더 만들기. 위치는 그대로입니다.
- cd terminal-practice: 연습 폴더에 들어가기.
- cd ..: 한 단계 위로 돌아가기. ~는 내 사용자 폴더입니다.

교안 순서대로 한 줄씩 실행합니다: cd ~ → pwd → mkdir terminal-practice → ls → cd terminal-practice → pwd → cd .. → pwd.
이미 연습 폴더가 있다는 메시지는 다음 단계로 넘어갑니다. mkdir와 cd의 차이는 pwd로 확인합니다.

## 자료 준비와 이동

1. 실습자료.zip을 바탕화면에 압축을 풉니다. Windows: ZIP 오른쪽 클릭 → 모두 압축 풀기 → 바탕화면 선택. macOS: ZIP을 바탕화면으로 옮겨 더블클릭.
2. 압축을 푼 claude-work-lab에서 workbooks·templates·integrations를 찾습니다. 바깥 폴더가 하나 더 생겼다면 그 안으로 들어갑니다.
3. 경로 복사: Windows는 폴더 안 주소 표시줄에서 복사. macOS는 Finder에서 폴더 선택 후 Command + Option + C.
4. 셸명령/00_실습폴더로이동.txt의 대괄호를 내 경로로 바꿔 실행합니다. 큰따옴표는 유지합니다. pwd와 ls로 위치·내용을 확인합니다.
5. 교안의 node·claude 명령을 한 줄씩 실행합니다. Claude가 켜지면 한국어 요청을 입력합니다.
6. 다른 명령을 실행할 창이 필요하면 새 PowerShell·터미널 창을 열고 같은 cd 명령부터 실행합니다.

/login과 /grill-me는 Claude Code 안에, cd·node·claude 실행 명령은 셸에 입력합니다. 만든 파일은 파일 탐색기·Finder에서 찾아 엽니다.
