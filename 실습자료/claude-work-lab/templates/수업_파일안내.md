# Claude용 · 수업 파일과 기본 저장 위치

수강생은 하고 싶은 일을 자연어로 말한다. 입력 별칭과 저장 위치는 아래에서 **관련 항목만** 찾는다. 저장 경로를 수강생에게 고르거나 입력하도록 요구하지 않는다. 지정된 파일이 없거나 두 자료가 같은 별칭이면 짧게 확인한다. 외부 검색으로 누락된 업무 데이터를 채우지 않는다.

## 입력 별칭
| 수강생이 말한 자료 | 실제 파일 |
|---|---|
| 외부 유통사 미팅 메모 | input/hanbit-sales/meetings/01_외부유통사미팅.txt |
| 내부 주간 영업회의 | input/hanbit-sales/meetings/03_내부주간영업회의.txt |
| 내주간비용.xlsx | workbooks/내주간비용.xlsx |
| 수정후 비용표 / 주간비용_수정후.xlsx | workbooks/주간비용_수정후.xlsx |
| 다음 주 비용표 | workbooks/주간비용_다음주.xlsx |
| 오류 비용표 | workbooks/주간비용_오류.xlsx |
| 열누락 비용표 | workbooks/주간비용_열누락.xlsx |
| 내업무비용.xlsx | workbooks/내업무비용.xlsx |
| 처음 실습 비용표 | workbooks/주간비용_실습.xlsx |

## 설정과 후속 작업
- 회의록 스킬 양식은 templates/skills/meeting-minutes/스킬_빈칸양식.md. 인터뷰한 기준을 확인받아 프로젝트 스킬로 생성한다.
- 제공 weekly-report 스킬은 .claude/skills/weekly-report/SKILL.md. 입력과 출력이 생략되면 위 별칭/결과를 사용한다. 기준 금액은 스킬의 사용자 기준을 따른다. 다음 주 비교는 검사한 output/local-final 집계를 먼저 사용한다. 없으면 검사한 output/skill-run을 찾고, 둘 다 없으면 비교는 미확인이라고 알려준다.
- grill-me 설치는 .claude/skills/grill-me/SKILL.md. templates/skills/grill-me의 LICENSE와 SOURCE.md도 복사한다. 이미 다른 내용이 있으면 덮어쓰기 전에 확인한다.
- 인터뷰 후 구현 요청은 notes/내도구_구현요청.txt에 있다. 확인받은 계획으로만 만들고 기존 index.html을 보존한다.
- 모든 프로젝트에 쓸 규칙은 ~/.claude/CLAUDE.md, 이번 폴더의 규칙은 CLAUDE.md. 인터뷰·초안 확인 후 기존 내용을 백업하고 합친다. 권한 설정은 바꾸지 않는다.
- Excel 웹 보고서·슬라이드 도구는 templates/excel-web-app/01_웹보고서_스펙.md를 사용한다. 계산은 제공 local-report, 온라인 분석은 기존 auth-report의 runOnce를 재사용한다. scripts/excel-web-app의 로컬 서버와 output/excel-web-app 실행별 결과를 사용한다. 수강생에게 서버 명령·출력 경로·exe 빌드를 요구하지 않는다.
- 파일 감시는 integrations/automation/실행안내.md를 사용한다. 처음에는 실습 비용표 사본을 inbox/주간비용.xlsx로 준비하고 output/auto에 저장한다. 기존 입력이 있으면 보존한다. 별도 보이는 창에서 기준 50000, 최대 12회로 실행한다.
- Gmail은 integrations/gmail-mcp/README.md. 검사를 통과한 output/my-work/share.txt가 있으면 사용하고, 없으면 검사한 output/local-final/share.txt를 사용한다. 없거나 실패 결과면 멈춰 알려준다. 메일은 초안만 저장한다.

## 보존과 안내
원본과 다른 작업의 결과를 보존한다. 같은 보고서의 재실행은 제공 도구의 갱신/오류 보존 동작을 따른다. 그 외 동일한 결과 파일이 있으면 보존하고 새 이름을 쓰거나 덮어쓰기 전에 확인한다. 새 이름을 썼다면 실제 이름을 알려준다. 결과 파일과 여는 방법만 짧게 알려주고 실제 검사·미확인을 구분한다. 비용 계산·로그인 실행기·감시 코드는 임의로 변경하지 않는다.

## 짧은 학생 요청을 실행할 때
- 회의록 스킬은 meeting-minutes 이름과 제공 빈칸 양식으로 생성한다. 인터뷰는 한 번에 한 질문, 최대 3개. 확인한 기준만 스킬에 남긴다. 담당자·날짜를 지어내지 않는다.
- 프로젝트 규칙 인터뷰는 프로젝트 CLAUDE.md에만 저장한다. 기존 규칙을 백업·보존하며 권한 설정은 변경하지 않는다. 글로벌 규칙 파일은 이번 요청에서 수정하지 않는다.
- 비용 팀 설정은 templates/team-starter/.claude를 사용한다. 기존 정의 보존, 제공 호출명·검사 계약 유지, CLAUDE.md에 /team-dashboard 규칙 추가. 자료 확인·화면 제작·검수 역할을 설명한 뒤 요청받을 때 실행한다.
- 내 지출 보고서의 5,000원 이상 강조는 같은 입력으로 제공 도구의 기준 금액만 5000으로 바꿔 보고서를 재생성한다. 건수·총액을 재대조한다.
- Gmail의 “방금 메일 초안”은 현재 맥락의 검사한 보고서에 대응하는 email-draft.md 또는 share.txt이다. integrations/gmail-mcp/README.md의 초안 전용 절차·길이·검사 기준을 지킨다.
