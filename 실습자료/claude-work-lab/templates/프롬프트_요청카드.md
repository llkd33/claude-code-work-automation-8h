# 짧게 부탁하고, 필요한 것은 물어보게 하기

프롬프트는 AI에게 하는 부탁입니다. 메타프롬프트는 “어떻게 부탁하면 좋을까?”라고 AI에게 요청문 작성도 맡기는 것입니다.

처음에는 핸드북의 ‘자료부터 참고하도록 부탁하기’를 한 번 보냅니다. 이후 요청은 관련 파일과 원하는 결과만 짧게 적습니다. 새 대화에서는 시작 요청을 다시 보냅니다.

## 바로 만들기
```text
체크리스트 웹페이지 하나 만들어줘.
추가하고 완료 표시하고, 새로고침해도 남게 해줘.
index.html에 간단하게 만들어줘.
```

## 질문으로 기준 정하기
```text
회의록 정리하는 방법을 스킬로 만들고 싶어.
내가 중요하게 보는 것을 물어보고, 내 답으로 만들어줘.
```

## 요청문도 부탁하기
```text
매주 비용표로 보고서를 만들고 싶어.
어떻게 부탁하면 좋을까? 필요한 것을 물어보고 짧은 요청문을 써줘.
아직 보고서는 만들지 마.
```

질문에 답하고 초안을 확인한 뒤 “이대로 만들어줘”라고 부탁합니다. 제공 예시와 내가 작성한 요청 중 하나만 실행하면 됩니다.
