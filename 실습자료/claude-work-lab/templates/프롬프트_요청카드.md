# 짧게 부탁하고, 필요한 것은 물어보게 하기

프롬프트는 AI에게 하는 부탁입니다. 메타프롬프트는 “어떻게 부탁하면 좋을까?”라고 프롬프트 작성도 맡기는 것입니다.

처음에는 핸드북의 시작 프롬프트를 보냅니다. 그다음에는 관련 파일과 원하는 결과만 짧게 적습니다. 새 대화에서는 시작 프롬프트를 다시 보냅니다.

## 바로 만들기
```text
체크리스트 웹페이지 하나 만들어줘.
항목을 추가하고 체크하면 완료되고, 새로고침해도 남게 해줘.
간단하게 만들고 브라우저에서 열어줘.
```

## 질문으로 기준 정하기
```text
회의록 정리하는 방법을 스킬로 만들고 싶어.
내가 중요하게 보는 기준을 하나씩 물어보고,
내가 확인하면 그 기준으로 회의록 정리 스킬을 만들어줘.
```

## 프롬프트도 부탁하기
```text
매주 비용표로 보고서를 만들고 싶어.
어떻게 부탁하면 좋을까? 필요한 것을 물어보고 짧은 프롬프트를 써줘.
아직 보고서는 만들지 마.
```

질문에 답하고 초안을 확인한 뒤 “이대로 만들어줘”라고 합니다. 제공 예시와 내가 작성한 프롬프트 중 하나만 실행하면 됩니다.
