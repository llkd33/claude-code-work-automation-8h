# grill-me · 배우고 설치하고 써 보기

스킬은 반복할 작업의 레시피입니다. name은 부를 이름, description은 하는 일과 사용할 상황, 본문은 실행할 절차입니다.

1. 핸드북의 첫 도구 다음 단계에서 스킬 설명과 예시를 읽습니다.
2. 복붙텍스트/02a_Claude_스킬내용복붙설치.txt 전체를 Claude Code 안에 붙입니다. SKILL.md 본문이 포함돼 있습니다.
3. .claude/skills/grill-me/SKILL.md를 열어 name·description을 확인합니다.
4. 같은 폴더에서 Claude를 다시 시작한 뒤 /를 입력해 grill-me를 찾습니다.
5. 03_Claude_G1_기능인터뷰.txt의 빈칸을 채워 보냅니다. 질문 하나씩 답하고 계획을 확인합니다.
6. 04번 A3 프롬프트로 확인한 계획 파일을 읽게 하고 새 HTML을 만듭니다.

예: 체크리스트에 장소·준비물 남기기, 남은 일만 보기, 사진 메모에 날짜·상태 추가. 이번 기능과 다음 개선을 나눕니다. 기능은 최대 3개로 정합니다.
