# 회의록 스킬을 만드는 빈칸 양식

아래는 작성 재료입니다. 대괄호를 인터뷰한 기준으로 채워 .claude/skills/meeting-minutes/SKILL.md에 저장합니다. 이 파일 자체를 호출하지 않습니다.

```markdown
---
name: meeting-minutes
description: [무슨 메모를 어떤 보고서로, 언제 정리할지]
disable-model-invocation: true
---
# 회의록 작성 절차
## 입력과 독자
- 호출 뒤에 적힌 파일 경로와 출력 요청을 입력으로 사용한다.
- 입력: 사용자가 지정한 회의 메모 한 개
- 독자: [보고받을 사람]
## 처리 순서
1. 원문과 날짜·참석자를 읽는다.
2. 결정·제안·미정 내용을 구분한다.
3. [내가 정한 섹션과 형식]으로 정리한다.
4. 담당·마감·수치가 원문과 맞는지 대조한다.
## 지킬 기준
- 원문에 없는 결정·담당·마감은 미정으로 표시한다.
- 제안을 확정 수주로 바꾸지 않는다.
- 참고자료는 사용자가 지정한 경우만 읽고, 원문과 다르면 차이를 표시한다.
- 원본과 기존 결과를 보존하고 사용자가 지정한 새 출력에 저장한다.
```
