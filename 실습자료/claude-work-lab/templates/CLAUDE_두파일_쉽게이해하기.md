# CLAUDE.md 두 파일 · 인터뷰로 시작하기

사용자 공통(글로벌): ~/.claude/CLAUDE.md. 이 PC 내 계정의 여러 프로젝트에서 참고할 한국어·답변 형식 같은 규칙입니다.
프로젝트용(로컬): 실습 폴더/CLAUDE.md. 이번 업무의 자료 위치·원본 보존·결과 폴더 같은 규칙입니다.

두 파일을 함께 참고합니다. 프로젝트가 항상 무조건 이긴다고 생각하지 말고 서로 반대되는 규칙을 없앱니다. 이 과정에서 로컬은 프로젝트용이라는 뜻입니다. 별도 CLAUDE.local.md는 이번 실습에서 다루지 않습니다.

1. “나를 인터뷰해서 두 파일의 초안을 나눠 줘”라고 부탁합니다.
2. 질문에 내 업무·선호를 답합니다. 공통/프로젝트 초안을 읽습니다.
3. 기존 규칙을 보존하고 변경 부분을 확인한 뒤 “좋아, 적용해줘”라고 답합니다.
4. /memory로 파일을 확인하고 같은 폴더에서 Claude를 다시 켭니다.

하네스는 두 파일만을 뜻하지 않습니다. 규칙·자료·도구·스킬·담당자·검사로 구성한 작업 환경입니다. 규칙 파일은 모델을 훈련시키거나 실행 권한을 강제로 제한하는 장치가 아닙니다.

공식 자료: https://code.claude.com/docs/en/memory
