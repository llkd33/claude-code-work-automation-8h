# 첫 도구 요청 파일 · 비용 마감 체크리스트

## 할 일
코드를 모르는 비용 마감 담당자가 오늘 확인할 일을 빠뜨리지 않게 하는 작은 웹 도구를 만든다.

## 재료와 결과 예시
외부 패키지·로그인·서버 없이 하나의 index.html로 만든다. 화면은 한국어이며 제목/할 일 입력/목록/남은 개수가 있다. 기본 예시는 ‘비용표 저장 확인’, ‘합계와 증빙 대조’이다.

## 기능은3개
1. 빈 문장을 제외하고 항목 추가.
2. 완료 체크와 남은 개수 갱신.
3. 같은 브라우저에서 새로고침해도 목록·완료 상태 유지(localStorage). 저장 불가 오류는 안내.

## 확인 기준
항목2개 추가 →1개 완료 →새로고침 →2개와 완료 상태/남은1개 유지. 사용자 입력은 HTML로 해석하지 않고 텍스트로 표시한다. 다른 원본·실습자료는 바꾸지 않는다. 기존 index.html이 있으면 먼저 확인하고 원본을 보존할 새 이름으로 저장하며 실제 생성 파일명을 알려준다.

가능한 실행 검사를 수행한다. 실제 브라우저 확인을 하지 못하면 미확인이라고 쓴다. 파일을 직접 열고 클릭하는 검사는 사람이 마친다.
