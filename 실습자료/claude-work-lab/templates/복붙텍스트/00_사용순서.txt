복붙 텍스트 팩 · 먼저 읽기

오전 3H는 설명과 강사 시연, 오후 5H는 첫 웹페이지·회의록 스킬·내 업무 스크립트와 재사용 환경을 직접 만듭니다.
모든 템플릿은 UTF-8 텍스트입니다. 

1. 복붙템플릿.zip을 내려받아 압축을 풉니다.
2. 지금 단계의 파일을 메모장 또는 텍스트 편집기로 엽니다.
3. 사본을 저장하고 [대괄호 빈칸]을 내 말로 바꿉니다. 빈칸이 없으면 그대로 씁니다.
4. 요청 또는 명령만 전체 선택 → 복사 → 맞는 창에 붙이기 → 실행합니다.
5. 결과 파일을 열고 숫자와 동작을 확인합니다.

입력할 곳
Claude_ 파일: 터미널에서 Claude Code를 시작한 뒤 그 안에 붙입니다.
셸명령 폴더: 기본 터미널 연습·폴더 이동·설치에만 씁니다. 업무 실행 요청은 Claude Code 안에 붙입니다. 기본 명령 연습은 교안의 cd ~ → pwd → mkdir → ls → cd → cd .. 순서로 진행합니다. Claude를 다시 켤 때는 새 창에서 00_실습폴더로이동.txt로 먼저 같은 실습 폴더에 들어갑니다.
파일내용 폴더: 요청으로 보내지 않고 안내된 파일에 저장합니다.
작성예시 폴더: 읽어 보는 예시입니다. 내 요청과 함께 중복으로 보내지 않습니다.
이 00번 사용안내는 Claude나 셸에 붙이지 않습니다.

첫 도구 뒤 스킬 직접 만들기
스킬의 뜻·name·description·본문 작성법을 먼저 읽습니다.
02b번으로 일반 대화 인터뷰를 받고 내 보고 기준을 확인합니다.
저장된 meeting-minutes/SKILL.md를 읽고 기준을 직접 고친 뒤, 02c번 외부 미팅 → 02d번 내부 회의에 적용합니다.
그 다음 02a번 grill-me 설치 텍스트 전체를 Claude Code 안에 붙입니다. 제공 SKILL.md 내용이 포함되어 있으며 셸 설치 명령은 사용하지 않습니다.
같은 폴더에서 Claude를 다시 시작하고 /grill-me를 찾습니다.
두 번째 weekly-report는 05b번으로 제공 기준을 고친 뒤 05번으로 호출합니다.
팀 실행 전에는 05a번 하네스 설정으로 제공 정의와 규칙 한 줄을 설치합니다.

A3는 한 경로만
인터뷰 경로: G1 → 계획 요약 확인 → 실제 계획 파일 확인 → 04번 A3.
기록 파일명이 바뀌었다면 04번의 notes 경로만 바꿉니다.
인터뷰가 막히면: 파일내용/내도구_직접계획.txt의 빈칸을 채워 전체를 Claude에 전달합니다.
인터뷰 경로와 직접 작성 경로를 둘 다 실행하지 않습니다.

A8은 앱이 자동으로 보내는 분석 요청입니다. 복붙용 A8 요청 파일은 없습니다.
Windows 또는 macOS 실행 파일을 더블클릭합니다. 같은 입력을 두 번 분석하지 않습니다.
Gmail은 Module 3의 정규 연결 실습입니다. 연결과 초안 저장 도구를 먼저 확인한 뒤 한 초안만 저장합니다.
메일함 전체 검색이나 발송은 하지 않습니다.

사용량을 줄이는 진행
숫자 계산은 Claude에게 제공 도구 실행을 맡깁니다. 감시를 켠 뒤에는 파일만 바꿉니다. 자연어 실행 요청에도 사용량이 듭니다.
grill-me·weekly-report·담당자 정의와 규칙 양식은 제공합니다. meeting-minutes는 내 인터뷰 답으로 직접 만들고 수정합니다.
대화가 끝날 때마다 같은 설명이나 전체 결과물을 재작성하도록 요청하지 않습니다.
막히면 마지막 오류와 대상 파일 한 가지를 보냅니다.
파일 읽기·인터뷰 답변·위임도 사용량이 듭니다. 결과가 준비되면 같은 요청을 반복하지 않습니다.

파일내용 사용 방법
CLAUDE_규칙.txt: 내 역할 빈칸만 채워 실습 폴더의 CLAUDE.md에 저장합니다.
첫도구_명세.txt: 제공 templates/checklist-spec.md의 설명 사본입니다. 읽고 참고합니다.
업무스킬_예시.txt: name은 호출 이름, description은 언제 어떤 일을 할지 설명합니다. 원래 실행용 파일은 .claude/skills/weekly-report/SKILL.md입니다.
담당자_*.txt: 제공 정의의 읽기용 사본입니다. 05a번 Claude 설정 요청으로 3명의 .md 정의를 등록하므로 다시 설치하거나 이름을 바꾸지 않습니다.
.txt 파일만 저장했다고 스킬이 등록되지는 않습니다. 실행용 파일은 원래 위치와 .md 이름을 사용합니다.

Gmail 결과 확인
수신자·제목·숫자·미발송 상태를 Gmail 임시보관함에서 직접 확인합니다.
도구 응답의 초안 ID를 기록합니다. 저장 도구가 없으면 미완료로 끝내며 로컬 파일을 저장 성공으로 세지 않습니다.

내 업무 자료
04a번 요청 전에 workbooks/내업무비용.xlsx 사본을 준비합니다. 비용내역 탭에 필수 일곱 열로 2~5건을 적고 내 예상 건수·합계를 기록합니다. 실행기 명세와 시작 코드는 제공 파일입니다. 내 결과는 output/my-work, 공통 팀 결과는 output/local-final입니다.
09번 Gmail 요청의 경로는 output/my-work/share.txt로 바꿉니다. 내 실행기가 미완료라면 검사한 output/local-final/share.txt를 사용합니다.

스킬 창작: 02b 회의록 인터뷰 → 내 요약 확인 → 저장된 SKILL.md 읽고 기준 고치기 → 02c 외부 미팅 적용 → 02d 내부 회의 재사용. 그 뒤 02a grill-me 설치와 G1을 진행합니다. 오전 참고요청은 강사 시연용입니다.

연결 실습
04b 고객관리 앱 →04c 메모추가 →04d 보고서 5종 →04e 부분수정 →05c FAQ답변 →06a 팀기준변경. 해당 교안 단계에서만 사용합니다. 숫자 계산은 제공 도구, 작성과 실행 요청은 Claude가 맡습니다.

요청을 함께 만들기
첫 도구와 내 업무에서는 먼저 어떻게 부탁할지 물어봅니다. 제안된 요청을 고쳐 보내거나 제공 요청을 씁니다. 둘을 중복 실행하지 않습니다.
규칙 설정은 05d번 인터뷰로 사용자 공통과 이번 폴더의 규칙을 나눕니다. 두 초안을 확인한 뒤 적용을 부탁합니다.
팀은 비용 보고/회의 정리/고객 후속관리 중 하나만 고릅니다. 06b·06c는 비용 팀 설정·호출을 대신하는 경로이며, 전부 실행하는 목록이 아닙니다.
