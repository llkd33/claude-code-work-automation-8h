복붙 프롬프트 사용하기

1. 지금 단계의 프롬프트를 엽니다.
2. 필요한 제목·기준·수신자를 작성합니다. 저장 위치는 따로 정하지 않아도 됩니다.
3. Claude Code 안에 붙여 넣습니다. 셸 명령만 PowerShell/터미널에 입력합니다.
4. 결과 파일을 열어 확인합니다.

핵심: 체크리스트 → 회의록 스킬 → 비용 보고서 → 다음 주 보고서 → CLAUDE.md·보고서 스킬
정규 자동화 실습: 서브에이전트 3명 팀 → Excel 웹 도구 → 파일 변경 자동 갱신 → Gmail 초안
선택: 고객관리 앱·내 지출 보고서·팀 추가 비교

팀은 비용 보고·회의 정리·고객 후속관리 중 하나만 고릅니다.

AI가 제안한 프롬프트와 제공 프롬프트 중 하나만 실행합니다. 스킬 설치의 세부 설정은 Claude에게 맡깁니다.
