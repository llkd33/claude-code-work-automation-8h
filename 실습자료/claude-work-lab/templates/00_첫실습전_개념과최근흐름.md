# 처음 만나는 말 · 필요할 때 찾아보기

한꺼번에 외우지 않아도 됩니다. 핸드북을 따라 만들다가 궁금한 말만 찾아보세요.

## AI에서 LLM까지

| 말 | 쉬운 뜻 | 예시 |
| --- | --- | --- |
| AI | 컴퓨터가 판단·예측·글쓰기 등을 하게 하는 기술 | 사진 분류, 글 요약 |
| 머신러닝 | 데이터에서 패턴을 배우는 방법 | 판매 기록으로 수요 예측 |
| 딥러닝 | 여러 층의 신경망으로 복잡한 패턴을 배우는 머신러닝 | 사진에서 불량 찾기 |
| LLM | 많은 글을 학습한 언어 모델 | Claude의 회의록 요약·코드 작성 |

AI 안에 머신러닝, 그 안에 딥러닝이 있습니다. LLM은 딥러닝을 활용한 모델입니다.

## 말로 만들고, 직접 확인하기

- **프롬프트:** AI에게 할 일을 알려 주는 문장. “할 일을 추가하고 체크하는 페이지를 만들어줘.”
- **메타프롬프트:** 프롬프트 작성도 AI에게 맡기기. “필요한 것을 물어보고 짧은 프롬프트를 써줘.”
- **바이브 코딩:** 원하는 모습을 말하고 결과를 보며 만들고 다듬는 방식. 안드레 카파시가 2025년에 소개한 말입니다.
- **에이전트:** 목표를 받아 필요한 도구로 작업하고 다음 행동을 고르는 AI.
- **에이전틱 코딩:** AI가 계획·파일 작업·실행·확인을 이어 가며 도구를 만드는 방식.
- **스펙:** 무엇을 만들고 어떻게 확인할지 적은 문서. 이 문서를 기준으로 만들면 Spec Driven 방식입니다.

“버튼을 만들어줘” → 만든 화면을 누르기 → “버튼을 더 크게 해줘”처럼 작은 일부터 해 봅니다.

## 만든 방법을 다시 쓰기

| 말 | 역할 | 수업에서 하는 일 |
| --- | --- | --- |
| CLAUDE.md | 반복해서 지킬 규칙 | 원본 보존, 한국어로 짧게 답하기 |
| Skill | 반복 작업의 절차 | 다른 회의 메모도 같은 양식으로 정리 |
| 서브에이전트 | 나눠 맡은 일을 하는 AI 담당자 | 자료 확인·작성·검수 세 역할 |
| MCP | AI와 외부 도구를 연결하는 방식 | Gmail에 초안 저장 |
| 하네스 | AI가 일할 규칙·도구·역할·확인 방법을 갖춘 환경 | 위 요소를 한 업무에 맞춰 준비 |

**최근 흐름은 답변 한 번에서 파일·도구를 쓰는 작업 흐름으로 넓어지는 것**입니다. 수업에서는 작게 만들기 → 확인하기 → 같은 방법으로 다시 쓰기로 경험합니다. [에이전트와 워크플로 설명](https://www.anthropic.com/engineering/building-effective-agents) · [스킬 안내](https://code.claude.com/docs/en/skills)

## 실습에서 볼 파일과 화면

- **터미널:** 글자로 프로그램을 켜는 창. `claude`로 Claude Code를 켜면 한국어로 부탁합니다.
- **HTML:** 브라우저로 여는 웹 화면 파일.
- **Markdown(.md):** 제목·목록·표를 적는 문서. 텍스트 편집기로 봅니다.
- **Excel(.xlsx):** 행과 열로 정리한 자료.
- **컨텍스트:** 지금 일을 위해 AI가 참고하는 정보.
- **토큰:** AI가 글을 읽고 쓸 때 처리하는 단위. 필요한 자료만 참고하면 불필요한 읽기를 줄일 수 있습니다.

내 업무의 사실과 취향은 내가 알려 주고, 숫자와 동작은 실제 결과를 열어 확인합니다.
