# Excel 하나로 보고서·슬라이드를 만드는 웹 도구

수강생은 “내 엑셀 하나로 보고서와 슬라이드를 만드는 웹 도구”를 요청한다. 이 문서는 Claude가 확인할 제작 기준이다. 파일·서버 경로를 수강생에게 입력하라고 요구하지 않는다.

## 먼저 인터뷰
- 누구에게 보여 줄지, 보고서에서 먼저 볼 내용, 슬라이드에서 보여 줄 내용을 한 번에 하나씩 최대 3개 질문한다.
- 보고서 + 발표 슬라이드 3장을 기본으로 하고, 공유 문안은 필요하면 함께 만든다. 기능을 늘리기 전에 사용자의 계획 확인을 기다린다.
- 가상 예시 입력은 workbooks/주간비용_다음주.xlsx. 개인 자료는 그 사본만 사용한다. 열이 다르면 매핑을 물어보고, 제공 비용 양식으로 작은 범위를 먼저 맞춘다. 없는 숫자는 만들지 않는다.

## 웹 화면
- 로컬 브라우저에서 Excel 파일 한 개를 선택한다.
- 선택한 파일명과 만들 결과를 보여 주고 실행한다. 중복 실행은 막는다.
- 진행 중·완료·오류를 표시한다. 실패를 성공으로 보이지 않는다.
- 완료되면 “보고서 보기”, “슬라이드 보기”, 필요하면 “공유 문안 복사”를 제공한다.
- 다른 사람이 접속하는 온라인 서비스로 배포하거나 로그인·공유 DB를 추가하지 않는다. 처음에는 이 PC의 127.0.0.1에서 사용한다.

## 제공 계산과 Claude 분석 재사용
- integrations/local-report/weekly-report.cjs의 runReport로 원본을 검사·집계한다. 새 계산 코드를 만들거나 제공 계산을 바꾸지 않는다.
- 온라인 분석이 필요하면 integrations/auth-report/launch.cjs의 runOnce를 래퍼 서버에서 재사용한다. 이 PC에 로그인된 Claude Code를 사용하며 인증·응답 검사는 기존 흐름을 따른다.
- 업로드별 작업 폴더를 분리하고 .xlsx 사본 한 개만 해당 inbox-auth에 넣는다. runOnce({root: 작업폴더})의 실제 반환 directory를 사용한다. 기존 입력과 보고서를 덮어쓰지 않는다.
- 파일 읽기·명령 실행이 필요한 처리는 로컬 Node 서버에서 한다. 브라우저에 인증 파일·토큰을 보내지 않는다. 서버는 127.0.0.1에만 바인딩한다. 업로드 이름을 경로/셸 명령으로 사용하지 말고 허용된 .xlsx 사본 이름을 생성한다. 10MB 제한을 유지한다.
- 웹 페이지를 열 때 자동으로 분석하지 않는다. 사용자가 요청한 실행 한 번에 Claude 분석도 한 번만 한다. 계산 실패면 분석하지 않는다.
- 실제 Claude 분석 실패 시 숫자 계산 성공과 구분해 오류를 표시한다. 가짜 AI 분석으로 채우지 않는다.

## 결과
- report.html: 기존 제공 보고서의 숫자를 사용한 웹 보고서
- analysis.md: 실제 Claude 분석 내용과 확인할 질문. 온라인 분석을 하지 않았다면 미실행이라고 표시
- slides.html: 브라우저에서 보는 발표 슬라이드 3장. ① 한 줄 결론·건수·총액 ② 부서별 금액 ③ 확인할 질문·다음 행동. 좌우 이동과 인쇄/PDF 저장을 제공한다. PowerPoint 파일과 구분해 안내한다.
- share.txt: 요청한 경우 6줄 이내의 공유 문안
- summary.json·run-state.json: 제공 집계와 이번 실행 상태
- 결과 숫자는 한 번 계산한 같은 집계를 공유한다. 분석 문장을 HTML로 실행하지 않고 텍스트로 표시한다. 원인과 효과는 근거가 없으면 가설/확인 필요로 쓴다.
- 생성 코드 기본 위치는 scripts/excel-web-app, 결과 기본 위치는 output/excel-web-app의 실행별 폴더. 기존 코드가 있으면 보존하고 사용한 실제 위치를 알려준다.

## 확인
1. 실습 다음 주 파일을 선택해 12건·1,130,900원인지 대조한다.
2. 보고서와 슬라이드의 숫자가 같은지 본다.
3. 입력 사본을 바꿔 한 번 더 실행하고 새 결과가 보이는지 본다. 같은 파일을 중복 분석하지 않는다.
4. 오류 입력은 실패로 표시하고 이전 성공 결과를 보존한다.
5. 실제 브라우저 검사와 Claude 응답 여부를 구분해 알린다. 실행하지 않은 검사는 미확인이다.

학생에게 서버 실행 코드를 치게 하지 않는다. Claude가 로컬 서버를 실행하고 브라우저 주소와 종료 방법을 알려준다. 실행기 소스는 분석 호출의 참고자료로 재사용하며 Windows exe 빌드는 이 웹 실습에서 하지 않는다.
