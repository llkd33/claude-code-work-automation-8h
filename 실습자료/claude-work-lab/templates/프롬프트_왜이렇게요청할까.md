# 부탁하는 말도 함께 만들기

“이런 일을 하고 싶은데 Claude에게 어떻게 부탁하면 좋을까?”로 시작합니다. AI가 질문하거나 초안을 주면 입력·결과·확인 방법이 내 의도와 맞는지 봅니다. 그다음 실행할 요청 하나만 보냅니다.

- 입력 지정: 다른 파일을 읽지 않게 하려는 말입니다.
- 출력 지정: 파일을 어디서 열지 정하는 말입니다.
- 원본 보존: 다시 시작할 자료를 남기는 말입니다.
- 제공 도구 사용: 계산 코드를 반복해서 새로 만들지 않으려는 말입니다.
- 실제 결과·미확인: 확인했다고 추측하지 않게 하는 말입니다.

완성 템플릿과 내가 만든 요청은 둘 중 하나만 실행합니다. 먼저 작은 파일 한 개를 성공시킨 뒤 다음 기능을 붙입니다.
