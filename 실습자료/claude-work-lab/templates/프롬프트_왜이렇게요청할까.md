# 짧은 프롬프트에 필요한 것

**무엇으로, 무엇을 만들지** 적습니다. 아직 정하지 못했다면 “필요한 것을 물어봐 줘”라고 해도 됩니다.

- **쓸 자료:** `@`를 입력하고 파일을 고릅니다.
- **원하는 결과:** “총액과 부서별 금액이 보이는 보고서”처럼 적습니다.
- **확인할 것:** “원본 합계와 맞는지 확인해줘”처럼 한 가지만 붙입니다.

저장 위치는 Claude가 안내합니다. 원본 보존과 제공 계산 도구 사용은 시작 프롬프트에서 한 번 알려줍니다.

## 예시
```text
이 엑셀로 주간 비용 보고서를 만들고 싶어.
어떻게 부탁하면 좋을까? 필요한 것을 물어봐 줘.
```

AI가 만든 프롬프트를 읽고 실행합니다. 보고서가 나오면 열어서 숫자와 화면을 확인합니다.
