# 짧은 요청에 필요한 것

처음 한 번 자료를 참고하는 방법을 알려주면, 매번 긴 설명을 붙이지 않아도 됩니다. 요청할 때는 **어떤 파일로 무엇을 만들지** 적습니다. 아직 잘 모르겠다면 “필요한 것을 물어봐 줘”라고 부탁합니다.

- 파일 경로: 같은 이름의 다른 자료와 헷갈리지 않게 합니다.
- 결과 위치: 만든 파일을 쉽게 찾아 열 수 있게 합니다.
- 원본 보존·제공 계산 도구: 시작 요청과 README에 한 번 적어 둡니다.

자료를 고르는 데도 비용이 드므로, 전체 폴더를 매번 읽거나 매번 웹검색하게 하지 않습니다. 관련 자료부터 보고, 없는 설치·사용법만 공식 문서에서 확인합니다.

## 예시
```text
이 엑셀로 주간 비용 보고서를 만들고 싶어.
어떻게 부탁하면 좋을까? 필요한 것을 물어봐 줘.
```

내 답으로 요청문을 만들면 내용을 읽고 실행합니다. 숫자와 화면은 결과 파일을 열어 확인합니다.
