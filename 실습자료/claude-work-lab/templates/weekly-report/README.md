# 내 업무 Skill 만들기

기본 Skill은 실습 폴더 .claude/skills/weekly-report/SKILL.md에 이미 들어 있습니다.
메모장으로 열어 기본 기준 금액 50000원과 확인 조건 한 곳을 내 업무에 맞게 고칩니다.
같은 폴더에서 Claude를 새로 실행한 뒤 “/weekly-report 다음 주 비용표도 보고서로 만들어줘”라고 부탁합니다. 저장 위치는 제공 파일 안내에서 찾습니다.
실제 호출과 도구 실행 뒤 결과 파일을 열어 확인합니다. 파일만 존재하면 완료가 아닙니다.

Skill은 한 업무의 반복 절차, CLAUDE.md는 폴더의 공통 규칙입니다. Skill은 데이터를 자동 최신화하거나 예약하지 않습니다.
