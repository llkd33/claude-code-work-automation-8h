# 수업 자료 찾아 쓰기

핸드북의 지금 단계에서 안내한 TXT 한 개를 엽니다. [대괄호]만 내 내용으로 고치고 요청이나 명령 전체를 맞는 창에 붙여 넣습니다.

| 자료 | 볼 때 | 쓸 곳 |
| --- | --- | --- |
| 첫 실습 전 개념·최근 흐름 MD | 오전 설명을 다시 보고 싶을 때 | 읽기 |
| checklist-spec.md | 첫 체크리스트의 완성 조건 확인 | 읽고 확인한 뒤 A2에서 @로 지정 |
| hanbit-sales의 메모·제품·보고 기준 | 회의록 스킬 인터뷰와 적용 | 지정한 자료만 Claude가 읽기 |
| 복붙텍스트의 Claude_ 파일 | AI에게 작업을 맡길 때 | claude로 연 대화 안 |
| 복붙텍스트의 셸명령 | 계산·실행기·감시를 실행할 때 | Claude가 실행 중이지 않은 PowerShell·터미널 |
| 파일내용/CLAUDE_규칙.txt | 공통 규칙 단계 | 읽고 수정해 CLAUDE.md로 저장 |
| 파일내용의 스킬·담당자 예시 TXT | 역할과 절차를 이해할 때 | 읽기 참고 |
| 02a 스킬 설치·05a 하네스 설정 요청 TXT | 실제 설치 단계 | 이 요청 전체만 Claude 안에 복사 |
| 내 업무 실행 카드 | 수업 뒤 같은 일을 다시 할 때 | 입력·명령·출력·확인 기준 참고 |

TXT에는 붙일 내용이, MD에는 개념·기준·사용법이 들어 있습니다. 텍스트 팩 전체를 AI에게 읽히지 않습니다. 이번 단계의 자료와 요청만 사용합니다.

02a에는 grill-me의 SKILL.md 내용이 이미 들어 있습니다. 05a는 제공 담당자 파일을 복사하게 합니다. 파일내용 폴더의 예시를 설치 요청에 다시 붙이지 않습니다.

## 내가 가져갈 것
- 작은 웹: 실제 HTML과 내가 확인한 추가·완료·새로고침 결과.
- 회의록: 내 기준을 담은 스킬, 외부·내부 회의록, 원문과 비교한 기록.
- 비용 자동화: 내 스크립트와 실행 카드, 계산·복구·다음 주 실행 결과, 자동 갱신 로그.
- 작업 환경: CLAUDE.md, 보고서 스킬, 담당자 3명과 실제 호출 결과, Gmail 초안.

확인하지 못한 동작은 내 실행 카드에 남깁니다. 다음에 입력 파일과 실행 명령만 보고 같은 결과를 다시 만들 수 있는지 확인합니다.
