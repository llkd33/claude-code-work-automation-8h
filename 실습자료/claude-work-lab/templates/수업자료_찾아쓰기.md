# 수업 자료 찾아 쓰기

핸드북에서 지금 단계의 프롬프트를 복사해 Claude Code 안에 붙입니다. Claude가 알려 준 결과 파일을 열어 직접 확인합니다.

| 자료 | 언제 보나요? |
| --- | --- |
| 실습 핸드북 | 순서대로 따라 할 때 |
| 복붙텍스트의 Claude 파일 | 화면 대신 파일에서 프롬프트를 복사할 때 |
| 복붙텍스트의 셸명령 | 처음 설치·로그인·폴더 이동을 할 때 |
| workbooks의 Excel·input의 메모 | 보고서나 회의록의 원본을 확인할 때 |
| templates의 스펙·규칙·스킬 예시 | 완성 기준이나 파일 모양이 궁금할 때 |

계산·팀 설정·웹 도구 실행·자동 갱신은 Claude에게 자연어로 맡깁니다. 긴 경로나 프로그램 명령을 외울 필요는 없습니다. 이번 단계에 필요한 자료만 참고하게 합니다.

## 내가 가져갈 것

- 체크리스트: 직접 눌러 본 웹페이지
- 회의록: 내 기준을 담은 스킬과 회의록 두 개
- 비용 보고서: 이번 주·다음 주 보고서와 다시 쓸 스킬
- 작업 환경: CLAUDE.md와 세 담당자의 결과
- 후속 자동화: Excel 웹 도구, 자동 갱신 확인, Gmail 초안

다음에 다시 쓸 **입력 파일, 프롬프트, 결과 파일, 확인할 숫자나 동작**을 메모합니다. 아직 안 된 부분도 함께 적습니다.
