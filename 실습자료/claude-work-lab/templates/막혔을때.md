# 한 곳만 고쳐 다시 검사

먼저 실제 실행 위치·입력 파일·최근 오류를 확인합니다. AI의 완료 문구 대신 파일과 검사 결과를 봅니다.

추가 AI 프롬프트가 필요한 경우 한 문장:

> [실제 파일/명령]에서 [관찰한 오류]가 났어. [원했던 동작]만 고치고 같은 검사로 다시 확인해줘. 원본을 보존해줘.

오류 수정은 기본8개 프롬프트 위치에 덧붙여 별도 기록합니다. API망 문제를 파일 코드 재제작으로 반복 해결하지 않습니다. 설치·계정이 막히면 사전준비표와 운영진 지원을 이용합니다.
