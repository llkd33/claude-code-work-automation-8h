하네스는 AI가 일할 자료·도구·규칙·담당자·확인 방법을 갖춘 환경입니다.

Excel·계산 도구 → CLAUDE.md → weekly-report → 담당자 3명 → 숫자·화면 확인.

1. 규칙 단계: 내 역할과 원본 보존 기준을 CLAUDE.md에 저장합니다.
2. 스킬 단계: weekly-report의 기준 금액을 내 값으로 바꾸고 호출합니다.
3. 팀 단계: 05a_Claude_하네스설정.txt를 Claude Code 안에 붙입니다. 제공 정의를 복사하고 팀 호출 규칙 한 줄을 추가합니다.
4. 같은 폴더에서 Claude를 다시 시작합니다. /agents에서 3명을 찾고 /team-dashboard로 호출합니다.
5. 새 입력을 넣었을 때도 같은 규칙과 검사 기준을 쓰는지 봅니다.

공통 규칙은 CLAUDE.md, 반복 절차는 SKILL.md, 담당자는 .claude/agents의 .md 파일에 둡니다. 파일 이름을 외우기보다 어떤 역할을 하는지 설명해 보세요.
