# 팀은 하나만 고릅니다

비용 보고 팀은 기존 templates/team-starter 경로를 따릅니다. 아래는 비용 팀 대신 실행할 대안 팀입니다. 사용자용 글로벌 규칙과 원본·기존 정의는 보존합니다. 동일 파일은 유지하고 내용이 다르면 확인 후 진행합니다.

- 회의정리: templates/team-options/회의정리/.claude의 agents 3개를 프로젝트 .claude/agents로, skills/meeting-team를 프로젝트 .claude/skills로 복사한다. 재시작 후 /agents에서 meeting-team-checker, meeting-team-writer, meeting-team-reviewer를 확인하고 /meeting-team로 실행한다. 입력 input/hanbit-sales/meetings/01_외부유통사미팅.txt; 결과 output/meeting-team/회의록.md.
- 고객후속관리: templates/team-options/고객후속관리/.claude의 agents 3개를 프로젝트 .claude/agents로, skills/followup-team를 프로젝트 .claude/skills로 복사한다. 재시작 후 /agents에서 followup-team-checker, followup-team-writer, followup-team-reviewer를 확인하고 /followup-team로 실행한다. 입력 input/customer-app/가상고객_5명.csv; 결과 output/followup-team/다음연락.md.

각 담당자의 name은 부를 이름, description은 언제 어떤 일을 맡기는지입니다. 내가 적은 역할과 제공 정의를 비교합니다. 정의 파일만으로 실제 호출을 증명하지 않습니다.
설정 후 같은 폴더에서 Claude를 다시 시작하고 팀 스킬로 실제 세 이름의 위임 기록을 확인합니다. 대안 팀 경로에서는 비용 팀 /team-dashboard와 비용 화면 기준 변경을 실행하지 않습니다.
