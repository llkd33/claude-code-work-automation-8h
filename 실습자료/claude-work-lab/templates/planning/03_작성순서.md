# 내 계획 · 개인 실습

1. /grill-me 질문에 한 번씩 답하고 계획을 확인합니다.
2. 인터뷰 기록과 구현 프롬프트에서 기능·입력·결과·검사 기준을 읽고 미정 항목을 결정합니다.
3. 04번 A3 프롬프트로 확인한 계획 파일을 읽게 합니다. 기존 도구를 보존하고 새 파일을 만듭니다.
4. 새 파일을 열고 내 기준으로 검사해 기록합니다.

기능은 최대 3개, 화면은 1개로 정합니다. 인터뷰가 막히면 직접 작성 폼으로 합류합니다. 두 경로를 모두 실행하지 않습니다. G1 인터뷰·답변·확인은 A1–A8과 별도로 기록합니다.
