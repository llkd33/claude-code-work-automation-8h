# PRD 예시 · 한빛화학 고객 메모장

PRD(Product Requirements Document)는 누구의 어떤 불편을 줄이고, 무엇을 만들지 정한 요구사항 문서입니다. 아래는 수업용 한 장 예시입니다. 회사마다 형식은 달라도 목적·기능·확인 기준이 들어갑니다.

## 누구와 어떤 문제
- 사용자: 한빛화학 화장품 영업팀의 나
- 상황: 외부 미팅 뒤 고객 기록이 여러 메모에 흩어집니다.
- 목적: 미팅한 고객과 다음 연락할 대상을 놓치지 않습니다.

## 이번에 만들 기능
1. 고객 추가: 회사명·담당자·관심제품·상담상태를 입력합니다.
2. 고객 검색: 회사명 일부로 목록을 찾습니다.
3. 상태 변경: 신규·상담중·후속연락·완료 중 선택합니다.

## 저장과 범위
- 한 화면에서 사용하며 같은 기기·브라우저에 저장합니다.
- 새로고침하거나 닫았다 같은 주소로 열어도 기록이 남습니다.
- 회원가입·다른 직원과 공유는 다음 단계로 남깁니다.
- 처음에만 제공된 가상 고객 5명을 불러옵니다.

## 직접 확인할 것
- 고객 1명 추가 → 6명 표시
- 회사명 검색 → 원하는 고객 표시
- 상태 변경 → 새로고침하고 다시 열어도 고객과 상태 유지

이번 작은 도구에서는 이 PRD를 스펙으로 사용할 수 있습니다. AI에게 읽어 달라고 한 뒤, 만들 범위를 확인합니다.
