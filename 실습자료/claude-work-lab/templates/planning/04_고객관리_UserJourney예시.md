# User Journey 예시 · 사람이 쓰는 순서

User Journey(사용자 여정)는 사용자가 어떤 상황에서 도구를 열고, 무엇을 하고, 어떤 결과와 느낌을 얻는지 적습니다. 기능 목록에 사용자의 상황·행동·마음을 연결합니다.

| 단계 | 상황과 행동 | 그때의 마음 | 앱이 도와줄 것 |
|---|---|---|---|
| 미팅 직후 | 새봄리테일 담당자를 만난 뒤 앱을 엽니다. | 어느 메모에 적었지? | 고객 목록을 보여 줍니다. |
| 기록 찾기 | 회사명 “새봄”을 검색합니다. | 빨리 찾고 싶다. | 해당 고객을 보여 줍니다. |
| 다음 일 정하기 | 상태를 “후속연락”으로 바꿉니다. | 이 고객에게 다시 연락해야겠다. | 바꾼 상태를 저장합니다. |
| 다음 날 | 같은 기기·브라우저·주소에서 다시 엽니다. | 기록이 남아 있어 안심된다. | 저장된 고객과 상태를 복원합니다. |

처음 등록하는 고객이라면 검색 전에 고객 추가를 합니다. “다시 열었을 때 정보가 남는다”는 확인 기준이 왜 필요한지도 이 여정에서 알 수 있습니다.
