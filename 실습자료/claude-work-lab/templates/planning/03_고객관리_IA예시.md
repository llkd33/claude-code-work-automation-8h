# IA 예시 · 한 화면에 무엇이 들어갈까요?

IA(Information Architecture)는 정보와 기능을 어디에 묶고 배치할지 정하는 구조입니다. 작은 앱은 아래처럼 한 화면의 묶음만 그려도 됩니다. 화면이 많아지면 화면과 메뉴의 연결도 함께 그립니다.

```text
한빛화학 고객 메모장 · 화면 1개
├─ 소개: 도구 이름 / 이 브라우저에 저장 안내
├─ 고객 추가: 회사명 / 담당자 / 관심제품 / 상담상태 / 추가 버튼
└─ 고객 목록
   ├─ 검색: 회사명 검색칸
   └─ 고객 행: 회사명 / 담당자 / 제품 / 상태 선택
```

- PRD의 “고객 추가” → 고객 추가 묶음에 배치
- PRD의 “고객 검색” → 목록 위 검색칸에 배치
- PRD의 “상태 변경” → 각 고객 행의 상태 선택에 배치

화면 디자인의 완성본이 아니라 정보 구조입니다. 상자와 선으로 그리거나 글로 적어도 됩니다.
