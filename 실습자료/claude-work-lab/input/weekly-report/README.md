# 주간 보고서 실습 · 같은 사실을 다섯 방식으로 전달하기

이 폴더의 자료는 모두 교육용 가상 데이터입니다. `@`로 이 안내를 선택하면 함께 읽을 네 파일이 적혀 있습니다. 폴더 전체를 읽을 필요는 없습니다.

## 이번 주 입력 네 가지

| 파일 | 역할 | 읽는 기준 |
|---|---|---|
| `01_이번주비용.csv` | 사실 데이터 | 수정후 Excel에서 가져온 41건. 전표번호·부서·품목·수량·단가·금액·처리상태를 확인합니다. |
| `02_보고기준.md` | 받는 사람과 보고 형식 | 팀장이 먼저 볼 결론, 예산 한도, 대시보드 항목, 메일 발송 금지를 따릅니다. |
| `03_지난주보고서.md` | 비교 기준 | 지난 기간 40건·2,333,300원으로 둔 교육용 기준입니다. |
| `04_이번주메모.md` | 업무 맥락 | 이번 주에 확인된 두 금액 변화, 팀장이 먼저 볼 항목, 아직 모르는 사실을 구분합니다. |

## 숫자 맞춰 보기

- 이번 주: 41건 · 2,363,300원.
- 지난주 기준: 40건 · 2,333,300원.
- 차이: 1건 증가 · 30,000원 증가.
- 부서 합계: 경영지원 721,300원 · 영업 586,000원 · 마케팅 1,056,000원.
- 이번 주 비용표의 처리상태: 완료 31건 · 진행 10건.
- 예산 검토 기준: 2,400,000원. 한도보다 36,700원 낮습니다. 이는 교육용 비교이며 지출 승인이나 절감 판정이 아닙니다.

30,000원 증가는 근거가 나뉩니다. E003 단가 변경으로 5,000원, 새 전표 E041로 25,000원입니다. 사은품 배송 문의가 늘었다는 메모는 현장 의견일 뿐이며 매출 변화 자료는 없습니다. 비용 변화의 원인을 배송 문의와 연결하지 않습니다.

## 만들 결과 다섯 가지

1. `weekly-report.md`: 팀장이 읽는 결론·숫자·확인할 일.
2. `weekly-report.html`: KPI와 부서별 금액을 보는 화면.
3. `team-summary.md`: 팀 채널에 붙일 6줄 이내 요약.
4. `email-draft.md`: 보내기 전 확인할 메일 초안.
5. `chart-data.csv`: 부서·금액 차트용 표.

모든 결과는 같은 총액과 건수를 사용합니다. 부서 금액 합은 총액과 같아야 합니다. 원인 분석은 확인된 사실과 구분해 “가능성”으로 씁니다. 이메일은 초안만 만들고 보내지 않습니다.
