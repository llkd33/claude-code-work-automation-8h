# 같은 자료, 다른 받는 사람

모든 자료는 교육용 가상 자료입니다. 보고서는 정답 문장이 아니라 숫자와 근거를 확인하며 다듬는 초안입니다.

| 자료 | 하는 일 | 직접 바꿔 볼 것 |
| --- | --- | --- |
|01_이번주비용.csv | 사실:수정후 Excel과 같은 41건 | 처음에는 그대로 사용 |
|02_보고기준.md | 기준:수신자·형식·검토 한도 | 한 줄만 내 기준으로 바꾸기 |
|03_지난주보고서.md | 비교:40건·2,333,300원 | 전주와 다른 수치 찾기 |
|04_이번주메모.md | 맥락:이번 주 상황과 팀장 관심 | 다음 행동에 반영됐는지 보기 |

네 파일을 읽고 결과를 다섯 개 만듭니다. 한 파일당 목적이 다릅니다.
weekly-report.md(팀장 보고) · weekly-report.html(대시보드) · team-summary.md(팀 공유) · email-draft.md(메일 초안) · chart-data.csv(차트 재사용).

원본 CSV는 앞 단계 수정후 Excel에서 발췌한 사본입니다. 비용 도구는 Excel을 검사합니다. CSV를 Excel 입력 자리에 넣지 말고, 검증된 output/local-final 집계와 행·총액을 대조합니다.
