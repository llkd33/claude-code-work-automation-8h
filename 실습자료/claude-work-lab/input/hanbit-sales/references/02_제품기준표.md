# 제품과 교육용 공급단가

모든 금액은 **원**, 수량 단위는 **개**입니다. 공급단가는 부가세 제외이며, 배송비·포장 변경비·개발비를 포함하지 않습니다. 세금·총 결제액을 계산하는 실습이 아닙니다. 공급금액 = 수량 × 공급단가로 계산합니다.

| 제품 코드 | 제품명 | 교육용 공급단가(원/개, 부가세 제외) | 수량 단위 |
|---|---|---:|---|
| HB-S01 | 수분 세럼 30mL | 6,000 | 개 |
| HB-C02 | 보습 크림 50mL | 8,000 | 개 |
| HB-T03 | 약산성 토너 150mL | 5,000 | 개 |

- 교육용 기본 상담 기준: 제품별 500개부터 상담합니다. 할인 규칙은 제공하지 않았습니다.
- 새봄리테일은 HB-S01 수분 세럼 30mL **3,000개를 제안**했습니다. 참고 공급금액은 18,000,000원이지만 수주·출고는 미확정입니다.
- 모아뷰티는 HB-C02 보습 크림 50mL를 기반으로 OEM **2,000개 견적 초안**을 요청했습니다. 기본 제품만 계산한 참고 공급금액은 16,000,000원입니다. 포장 변경비·개발비가 미정이므로 최종 견적이나 확정 계약금액이 아닙니다.
- 제품 효능 시험, 제조 일정, 재고 수량은 제공되지 않았습니다. 임의로 품질·재고·납품 가능 여부를 보증하지 않습니다.
