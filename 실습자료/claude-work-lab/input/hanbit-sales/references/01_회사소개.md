# 한빛화학 회사 소개

한빛화학은 화장품 기초 제품을 만드는 가상 회사입니다. 자체 제품을 유통사에 공급하고, 외부 브랜드의 OEM 제품도 상담합니다. 여기서 OEM은 다른 브랜드 이름으로 제품을 만들어 공급하는 일을 뜻합니다.

## 이번 실습의 영업팀

| 사람 | 역할 |
|---|---|
| 이도현 | 영업팀장, 주간 보고 검토 |
| 김유나 | 유통사 상담, 주간 영업보고 작성 |
| 박민준 | OEM 브랜드 상담, 요구사항 정리 |
| 한서윤 | 제품개발 담당, 제조 가능 여부 검토 |

외부 미팅의 최지훈은 새봄리테일 유통 담당자, 오가은은 모아뷰티 브랜드 담당자입니다. 두 사람 모두 가상 인물입니다. 누리상사·가온스토어도 가상 거래처이며, 이번 상담의 새봄리테일·모아뷰티와 별개입니다.
