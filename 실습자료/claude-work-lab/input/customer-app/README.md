# 고객관리 앱 실습 자료 · 가상 화장품 영업팀

실제 회사나 고객이 아닌 교육용 설정입니다. 목적은 미팅 후 다음 연락을 잊지 않도록 고객을 간단히 기록하고 다시 찾는 것입니다.

## 기본 입력 파일

`가상고객_5명.csv`에는 처음 화면에 넣을 고객 다섯 명이 있습니다.

| 열 | 의미 | 예시 |
|---|---|---|
| 고객번호 | 연습용 고유번호 | C001 |
| 회사명 | 상담한 가상 회사 | 새봄리테일 |
| 담당자 | 가상 연락 담당자 | 김하늘 |
| 관심제품 | 대화에서 관심을 보인 가상 제품 | 수분 세럼 |
| 상담상태 | 현재 후속 단계 | 신규·상담중·후속연락·완료 |

다섯 행은 초기 화면 확인용입니다. 처음 실행할 때 한 번만 넣고, 새로고침할 때마다 이 다섯 명으로 덮어쓰면 안 됩니다. 수강생이 추가한 연습 기록도 남아야 합니다.

## 기능을 고를 때 쓸 실제 상황

- 상담이 끝난 뒤 회사명과 담당자, 관심제품을 기록합니다.
- 다음 날 회사명 일부를 검색해 고객을 찾습니다.
- 연락을 마치면 상담상태를 후속연락 또는 완료로 바꿉니다.
- 한 화면에서 추가와 목록을 오가며 사용할 수 있습니다.

회사명 검색·고객 추가·상태 변경은 기능 후보입니다. 인터뷰로 수강생이 꼭 필요한 것만 고릅니다. 세 기능을 자동으로 모두 넣는다는 뜻은 아닙니다.

## 화면과 데이터의 약속

- 화면 파일은 `index.html`입니다. 기록은 같은 브라우저의 localStorage에 따로 저장합니다.
- 새로고침하거나 같은 로컬 주소를 다시 열어도 추가·수정한 값이 남아야 합니다.
- 처음의 가상 고객 다섯 명은 최초 준비 때 한 번만 불러옵니다.
- 브라우저 저장 데이터를 지우면 기록이 없어질 수 있습니다. 다른 사용자나 기기와 자동 공유되지 않습니다.
- 실제 고객 이름·전화번호·메일·거래 정보를 입력하지 않습니다.

## 확인할 테스트 자료

새 고객 입력 예시: 회사명 `한빛테스트상사`, 담당자 `홍예진`, 관심제품 `수분 세럼`, 상태 `신규`.

정상 입력이면 5명에서 6명으로 늘고, `한빛` 검색 결과는 한 건이어야 합니다. 상태를 `후속연락`으로 바꾸고 검색을 지운 뒤 새로고침해도 여섯 명과 변경 상태가 남아야 합니다. 회사명을 비워 추가하면 안내하고 저장하지 않아야 합니다.

기본 사양은 `templates/customer-app/01_고객관리_스펙.md`에 있습니다. 제공 서버 사용법은 `integrations/local-web/실행안내.md`를 참고합니다.
