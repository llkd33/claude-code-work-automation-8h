# 실습 입력자료 지도

교육용 가상 자료를 고를 때 쓰는 안내입니다. Claude Code에서 `@`를 입력하고 아래 파일을 목록에서 선택할 수 있습니다. 자료가 여러 개면 이 안내가 연결한 파일만 읽습니다.

## 자료의 우선순위

1. **원본 입력**에서 실제 숫자·문장을 읽습니다.
2. **기준 문서**에서 받는 사람·표시 방식·판단 범위를 읽습니다.
3. **완료 기준**으로 건수·합계·상태·누락 여부를 직접 대조합니다.
4. 자료에 없는 원인·일정·승인·배송 약속은 빈칸 또는 “확인 필요”로 남깁니다.

샘플은 현실적인 업무 상황을 연습하기 위한 창작 자료입니다. 실제 회사 실적·고객 정보·승인 답변으로 사용하지 않습니다.
