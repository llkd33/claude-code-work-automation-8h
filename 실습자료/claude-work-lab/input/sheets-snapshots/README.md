# 표 변경 감지 실습 자료

네 묶음은 교육용 가상 표입니다. `id`는 행을 구분하고, `team`, `amount`, `status`는 비교할 값입니다. TSV는 사람이 스프레드시트로 보기 쉽고 JSON은 프로그램이 읽기 쉽습니다. 번호가 같은 TSV와 JSON은 같은 자료입니다.

| 순서 | 파일 | 내용 | 기대 판단 |
|---|---|---|---|
| 1 | `01-initial.tsv` / `.json` | T001~T003, 합계 35,000원 | 처음 상태 |
| 2 | `02-same.tsv` / `.json` | 같은 행을 순서만 바꿔 배치 | 값 변경 없음. 변경 알림을 만들지 않음 |
| 3 | `03-changed.tsv` / `.json` | T002 금액·상태 변경, T004 새 행 추가 | T002 변경과 T004 추가를 구분. 합계 48,000원 |
| 4 | `04-malformed.tsv` / `.json` | 금액 칸이 숫자가 아닌 글자 | 비교를 멈추고 행·열 오류를 보고 |

실습은 먼저 1번을 기준으로 정하고 2→3→4 순서로 비교합니다. 4번의 잘못된 값을 임의로 숫자로 바꾸지 않습니다. 마지막에도 3번 정상 자료로 돌아가 결과를 확인합니다.
