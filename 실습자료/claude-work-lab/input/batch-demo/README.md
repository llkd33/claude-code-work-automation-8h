# 짧은 업무 메모 자료

세 자료 모두 교육용 가상 사례입니다. 업무 메모에서 사실·미정·다음 할 일을 골라 작은 표나 요약으로 바꾸는 연습에 씁니다.

| 파일 | 만들기 좋은 결과 | 기억할 사실 |
|---|---|---|
| `출장 정리.txt` | 확정 비용과 확인 중 비용 표 | 확정 164,500원, 영수증 확인 중 10,000원. 샘플 수령·계약은 미확정 |
| `행사 체크.txt` | 준비 항목·상태·담당 역할 표 | 17명은 회신 수이지 참석 확정이 아님. 샘플 30세트도 재고 확정이 아님 |
| `회의 메모.txt` | 결정·제안·할 일 정리 | 담당은 역할명으로 표시. 날짜가 없으면 미정 |

실제 개인 정보나 업무 자료를 추가하지 않습니다. 원문 메모를 보존하고, 모르는 사람 이름·마감일·승인 결과를 만들어 내지 않는지 결과를 대조합니다.
