# 한빛화학 상담 FAQ · 교육용 가상 자료

1. 주문 상담은 제품별 500개부터 받습니다. 할인 규칙은 제공되지 않았습니다.
2. HB-S01 수분 세럼30mL의 교육용 공급단가는 개당6,000원, 부가세 제외입니다.
3. HB-C02 보습 크림50mL의 교육용 공급단가는 개당8,000원, 부가세 제외입니다.
4. 배송일은 주문·재고·생산 일정 확인 후 안내합니다. 현재 확정 재고와 생산 일정은 없습니다.
5. OEM은 다른 브랜드 이름으로 제품을 만들어 공급하는 상담입니다. 포장 변경비·개발비는 별도 확인합니다.
6. 인증·효능 시험·독점 공급 가능 여부는 자료가 없습니다. 담당자 확인이 필요합니다.

가격·최소 수량·세금 기준을 그대로 표시합니다. 자료에 없는 효능·할인·배송일은 약속하지 않습니다. 이 문서는 고객에게 발송할 승인 답변이 아닙니다.
