# 고객 문의 답변 실습 자료

모든 회사·제품·단가·질문은 교육용 가상 사례입니다. 고객에게 실제로 보내는 답장이 아니라, 근거를 찾아 답변 초안을 만드는 연습입니다.

## 파일 세 개의 역할

| 파일 | 역할 | 무엇을 확인하나요? |
|---|---|---|
| `01_상담FAQ.md` | 답변 근거 | 최소 상담 수량, 교육용 단가, 배송·할인·인증 관련 확정 여부 |
| `02_고객질문_3개.txt` | 연습 질문 | 자료에 있는 질문, 자료에 없는 질문, 두 제품을 비교하는 질문 |
| `03_직접확인.md` | 검수 기준 | 계산값, 세금 표시, 약속하면 안 되는 내용 |

## 계산 예시

- 수분 세럼(HB-S01): 개당 6,000원. 600개 기본 공급금액은 3,600,000원입니다.
- 보습 크림(HB-C02): 개당 8,000원. 최소 상담 수량 500개 기준 4,000,000원입니다.
- 두 금액 모두 부가세 제외입니다. 주문 상담은 제품별 500개부터 가능합니다.

이 금액은 연습용 단순 곱셈이며 확정 견적이 아닙니다. 배송일은 주문·재고·생산 일정을 확인한 뒤 답해야 합니다. 자료에 할인, 효능, 인증, 독점 공급에 관한 근거가 없으면 “확인 필요”로 남깁니다.

## 완료 확인

1. 세 질문에 대한 초안을 만듭니다.
2. 숫자를 `03_직접확인.md`와 대조합니다.
3. 근거가 없는 배송일·할인·효능 약속이 들어가지 않았는지 확인합니다.
4. 사람이 검토하고 승인하기 전에는 발송하지 않습니다.
