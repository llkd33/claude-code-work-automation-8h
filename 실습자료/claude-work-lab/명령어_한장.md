# 명령어 한 장 · 외우지 말고 필요한 줄만 사용

PowerShell 또는 macOS 터미널을 열고 cd 명령으로 claude-work-lab에 들어갑니다. 아래 명령은 그 창에 한 줄씩 복사합니다. Claude가 실행 중이면 창을 하나 더 열고 같은 cd 명령부터 실행합니다. [시작하는 방법](templates/터미널_한장.md).

| 명령 | 용도 |
| --- | --- |
| node --version | 계산 도구 실행기 확인 |
| npm --version | 패키지 설치 도구 확인 |
| claude --version | Claude 설치 확인 |
| claude doctor | 설치·설정 진단 |
| npm ci --prefix integrations/local-report | 고정 계산 라이브러리 설치 |
| claude | 수업 Claude 시작 |

파일 탐색기 또는 Finder에서 workbooks·templates·integrations를 찾습니다. 자동화 단계에서는 실행 창을 2개 열어 A/B로 구분하고 둘 다 같은 실습 폴더에서 시작합니다.

Claude 안에서 사용할 기본 명령:

| 명령 | 용도 |
| --- | --- |
| /model | Claude 안에서 모델 목록을 열어 선택 |
| /help | 현재 버전의 사용 가능한 명령 보기 |
| /clear | 새 작업 대화 시작. 실제 파일은 삭제하지 않음 |
| /compact | 긴 대화 요약 |
| /permissions | 실행 권한 확인 |
| /rewind | 체크포인트 복구. 모든 외부/셸 작업을 되돌리는 것은 아님 |
| /exit | Claude 종료 |

Plan은 먼저 읽고 계획을 검토하는 모드입니다. 수업 기본 default는 작업 권한을 확인하며 진행합니다. Auto의 지원·설정은 계정/조직/버전에 따라 확인하고 자동 승인으로 단순화하지 않습니다. 모드 이름을 외우기보다 실행 대상·범위를 확인합니다.

자동 반복 중단은 **감시 터미널 A에서 Ctrl+C**. 종료 로그와 상태를 직접 읽습니다. Claude 종료와 별도 Node 터미널 종료는 서로 다릅니다.

## 먼저 익힐 기본 명령

pwd는 현재 위치, ls는 파일 목록, mkdir는 새 폴더 만들기, cd는 폴더 이동입니다. cd ..는 한 단계 위로 돌아갑니다. 처음에는 핸드북의 기본 명령 시연을 보고 오후 준비에서 같은 명령을 직접 써 봅니다.

자료는 바탕화면에 압축을 풉니다. Windows는 ZIP 오른쪽 클릭 → 모두 압축 풀기 → 바탕화면 선택. macOS는 ZIP을 바탕화면으로 옮겨 더블클릭합니다. 그 안의 claude-work-lab 전체 경로를 복사해 cd 텍스트의 대괄호만 바꿉니다. OneDrive 등 실제 바탕화면 위치를 그대로 사용합니다.
