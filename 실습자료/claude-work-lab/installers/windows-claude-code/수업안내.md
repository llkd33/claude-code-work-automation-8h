# Windows 설치 도우미

Windows 참가자가 기본 설치 명령에서 막힐 때 사용하는 선택 자료입니다. Mac에서는 필요하지 않습니다. 먼저 README를 읽고, PowerShell 설치 명령이 잘 작동한다면 이 도구는 건너뛰세요.

`install-claude.bat`은 같은 폴더의 PowerShell 파일을 실행합니다. 설치 과정에서 Claude Code를 인터넷으로 내려받고, 사용자 PATH를 수정할 수 있습니다. 기존 설치가 충돌하면 제거를 제안할 수 있으며, 화면에 표시되는 질문을 읽고 선택해야 합니다. `-Yes` 옵션으로 무인 설치하지 마세요. 수업에서는 기본 실행만 다루고 이 스크립트는 실행하지 않습니다.

파일 출처: 강사가 제공한 `claude-code-windows-installer` 폴더. 수업 자료에는 원본 파일을 그대로 복사했습니다. 설치에 필요한 네트워크와 Windows 권한은 컴퓨터 환경에 따라 다를 수 있습니다.
