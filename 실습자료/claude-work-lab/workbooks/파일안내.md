# 비용 Excel 실습 자료 안내

모든 회사·담당자·거래처·금액은 수업용 가상 자료입니다. 파일마다 쓰임이 다릅니다. 파일 이름이 비슷해도 서로 바꿔 쓰지 않습니다. 오류·누락 파일은 해당 실습에서만 엽니다.

## 파일 고르기

| 파일 | 자료 내용 | 수업에서 하는 일 | 정상 기준 |
|---|---|---|---|
| `주간비용_실습.xlsx` | 기준 입력 40건, 2026-09-07~09-11 | 사본을 만들어 한 건 수정·추가 연습 | 40건 · 2,333,300원 |
| `주간비용_수정후.xlsx` | E003 단가 수정 및 E041 한 건 추가 | 보고서·메일 초안·팀 작업의 기준 입력 | 41건 · 2,363,300원 |
| `주간비용_다음주.xlsx` | 2026-09-14~09-17, 다음 기간 12건 | 같은 절차로 다음 주 결과 만들기, Excel 웹 도구 시연 | 12건 · 1,130,900원 |
| `주간비용_확장연습_120건.xlsx` | 6개 부서, 8개 비용 종류, 120건 | Excel 필터와 사본 수정 연습 | 원본 기준 120건 · 20,168,700원 |
| `주간비용_오류.xlsx` | 중복 전표 등 오류 확인 연습 | 오류를 알아차리고 정상 입력으로 복귀 | 정상 입력이 아님. 정상 결과를 지우지 말 것 |
| `주간비용_열누락.xlsx` | 기준 입력에 필요한 열이 빠진 연습 파일 | 어떤 열이 빠졌는지 설명하기 | 정상 입력이 아님. 임의로 열을 만들어 계산하지 말 것 |

Claude Code에서 `@`를 입력한 다음 파일 목록에서 고릅니다. 예: `@workbooks/주간비용_다음주.xlsx`. 파일이 목록에 없으면 먼저 Claude Code를 실습 자료 폴더에서 열었는지 확인합니다.

## 공통 열 읽기

정상 비용내역 시트에는 아래 항목이 있습니다.

| 열 | 뜻 | 읽을 때 주의할 점 |
|---|---|---|
| 전표번호 | 각 비용 행의 식별 번호 | 중복 여부를 살핍니다. |
| 사용일 | 비용을 쓴 날짜 | 보고 기간을 확인합니다. |
| 부서 | 비용을 사용한 부서 | 부서 합계는 전체 합계와 맞아야 합니다. |
| 품목·비용유형 | 무엇에 얼마를 썼는지 | 품목명은 기록이고, 이유나 성과를 증명하지 않습니다. |
| 수량·단가·금액 | 계산에 필요한 숫자 | 금액은 수량 × 단가인지 확인합니다. |
| 처리상태 | 진행 또는 완료 | 완료는 결제 완료를 뜻하지 않습니다. |
| 담당자·거래처 | 교육용 인물·업체 이름 | 전부 가상 정보입니다. |
| 결제방법·프로젝트·메모 | 비용 맥락을 설명하는 값 | 맥락 참고용이며 지출 효과를 단정할 근거는 아닙니다. |

금액은 원화입니다. 일부 보고서 자료에 있는 해외 USD 참고 수치는 원화 합계에 더하지 않습니다. “진행”은 처리 상태이며 미승인·미결제와 동일한 뜻이라고 추측하지 않습니다.

## 40건 기준표에서 바꿔 보는 내용

파일 탐색기/Finder에서 `주간비용_실습.xlsx`를 복사해 `내주간비용.xlsx`로 이름을 바꾸고, 복사본을 Excel에서 엽니다. 원본은 그대로 둡니다. Excel에서 전표번호 E003을 찾고 단가를 10,000원에서 15,000원으로 바꿔 저장합니다. 금액 열은 수량×단가 수식으로 다시 계산됩니다.

- E003의 단가: 10,000원 → 15,000원. 한 건 금액이 5,000원 늘어납니다.
- E041 추가: 수량 1 × 단가 25,000원. 총액이 25,000원 늘어납니다.
- 수정 후: 41건 · 2,363,300원.
- 부서 합계: 경영지원 721,300원 · 영업 586,000원 · 마케팅 1,056,000원.
- 처리상태 건수: 완료 31건 · 진행 10건.

40건 기준의 부서 합계는 경영지원 721,300원 · 영업 586,000원 · 마케팅 1,026,000원입니다. 수정 후 마케팅 금액이 30,000원 늘어난 것은 E003 변경 5,000원과 E041 추가 25,000원의 합입니다.

## 다음 주 12건 데이터 읽기

`주간비용_다음주.xlsx`는 다른 기간의 별도 실습 자료입니다. 수업 시연과 반복 실행에 사용하며 40건 기준표에 합치지 않습니다.

- 날짜 범위: 2026-09-14~09-17, 하루 3건씩.
- 부서별: 경영지원 398,100원 · 영업 235,800원 · 마케팅 497,000원.
- 처리상태: 완료 8건 · 진행 4건.
- 진행 4건: W103 뉴스레터 모집 광고 175,000원, W105 신제품 제안 자료 42,000원, W109 촬영 렌즈 대여 110,000원, W110 공용 마우스 70,500원.
- 프로젝트 맥락: 신규고객, 가을캠페인, 사내교육, 콘텐츠제작, 사무환경.
- 정상 기준: 12건 · 1,130,900원.

이 숫자만으로 어느 비용이 낭비인지 결론 내릴 수 없습니다. 승인·정산 예정 메모도 확정 사실과 구분합니다.

## 결과 대조

1. 행 수와 전표번호 수가 맞는지 확인합니다.
2. 수량 × 단가가 각 금액과 맞는지 봅니다.
3. 부서별 합계를 더한 값이 총액과 맞는지 봅니다.
4. 진행·완료 건수의 합이 전체 건수와 맞는지 봅니다.
5. 다음 주나 수정후 파일의 요약·보고서는 해당 파일의 기준값과 대조합니다.

이 안내는 데이터 읽기용입니다. 제공 계산 도구·엑셀 원본·오류 검증 규칙을 고치지 않습니다.

## 더 많은 행으로 연습하기

`주간비용_확장연습_120건.xlsx`는 수업용 가상 데이터입니다. 실제 인물·거래처 정보는 없습니다. `비용내역` 시트에 14개 열이 있고, 2026-10-12~16의 기록을 날짜·부서·상태·비용 종류로 필터링할 수 있습니다. `실습안내` 시트에는 수정 전 건수·합계와 부서·비용 종류별 기준이 있습니다.

이 파일도 먼저 복사한 뒤 Excel에서 직접 바꾸세요. 예를 들어 X001의 단가를 1,800원에서 2,800원으로 바꾸면 금액과 합계가 1,000원 늘어납니다. 보고서에서 120건·20,169,700원을 확인할 수 있습니다. 이 확장 실습은 40건·41건 정답을 확인하는 기본 실습과 별개입니다.
