# 실습 자료를 참고하는 방법

- 먼저 `AI_참고_색인.md`를 읽고, 지금 할 일에 연결된 자료만 추가로 확인합니다. 폴더 전체와 대용량 원본을 한꺼번에 읽지 않습니다.
- 실습의 목적·질문·파일·정답은 이 폴더의 교육 자료를 기준으로 합니다. 빈 값이나 가상 정보는 사실처럼 채우지 말고 확인이 필요하다고 표시합니다.
- 비용 계산은 `integrations/local-report/실행안내.md`의 제공 도구와 공식을 사용합니다. 계산 코드를 새로 만들거나 바꾸지 않습니다.
- `workbooks/`의 원본, 이전 정상 결과, 오류 재현 파일은 덮어쓰지 않습니다. 필요한 경우 먼저 사본을 만들고 그 사본에서 작업합니다.
- 고객·회사 자료는 모두 교육용 가상 데이터입니다. 실제 개인정보, 비밀번호, API 키를 만들거나 입력하지 않습니다.
- 도구를 실행하기 전 대상 파일과 저장 위치를 확인합니다. 실행하지 않은 검사·열어보지 않은 결과를 완료했다고 말하지 않습니다.
- 자료에 없는 최신 사용법만 공식 제품 문서에서 확인하고, 무엇을 찾아봤는지 한 줄로 밝힙니다. 수치·사실·취향을 웹 검색으로 추정하지 않습니다.
- 설명은 한국어로 짧고 쉬운 말로 합니다. 학생에게는 긴 경로·스키마 대신 화면에서 할 일과 확인할 결과를 안내합니다.
