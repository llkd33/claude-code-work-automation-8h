내 업무 실행 카드

입력: workbooks/내업무비용.xlsx
실행: 아래 요청을 Claude Code 안에 붙입니다.
결과: output/my-work/report.html
검사: output/my-work/verification.json
내 기준 금액: [정수 금액]
예상 건수·합계: [내가 계산한 값]
실제 건수·합계: [실제 결과]
정상 백업: workbooks/내업무비용_정상백업.xlsx
Gmail 문안: output/my-work/share.txt
Gmail 초안 ID·사람 확인: [실제 결과]

다음 사용: 입력 사본을 새 자료로 바꾸고 저장 → 같은 스크립트 실행 → 검사 상태와 숫자 대조.
오류 복구: 오류 행과 항목 기록 → 정상 백업을 같은 실행 파일 이름으로 복사 → 같은 요청으로 재검사.
공통 팀 입력·결과는 이 카드의 내 입력·결과와 별도로 보관합니다.

복사할 실행 요청
scripts/my-workflow.cjs를 다시 실행해줘. 건수·총액을 확인해줘.
오류가 나면 이전 정상 보고서는 남기고 이유를 알려줘.
