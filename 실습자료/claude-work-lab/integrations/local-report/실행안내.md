# Claude가 보는 비용 보고서 실행 안내

- 제공 도구: integrations/local-report/weekly-report.cjs. 계산 코드는 변경하지 않는다.
- 이 실습 폴더에서 node integrations/local-report/weekly-report.cjs "입력 경로" "결과 폴더"를 실행한다. 경로는 사용자 요청의 값을 사용한다.
- 기준 금액 요청이 있으면 --threshold 정수금액을 붙인다.
- 실행 결과의 건수·총액·verification.json을 확인한다. 실패를 성공으로 바꾸거나 입력을 임의로 고치지 않는다.
- 원본과 다른 결과를 보존한다. report.html의 실제 경로와 여는 방법만 짧게 알려준다.
