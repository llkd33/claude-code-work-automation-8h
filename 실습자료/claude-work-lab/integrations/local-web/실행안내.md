# Claude가 보는 로컬 웹 실행 안내

- 제공 서버:node integrations/local-web/serve.cjs output/customer-app 4318
- 127. 0. 0. 1에만 열고 output/customer-app 안의 파일만 제공한다. 서버 DB와 업로드는 없다.
- 별도 실행 창 또는 관리 가능한 백그라운드 실행으로 켠다. http://127. 0. 0. 1:4318/에 실제 응답이 오는지 확인한다.
- 같은 실습을 다시 열 때도 같은 주소를 사용한다. 서버를 종료해도 고객 기록은 브라우저 localStorage에 있다.
- 포트를 다른 앱이 쓰면 그 앱을 종료하지 않는다. 사용자에게 충돌을 알리고 대체 주소를 선택한다. 주소가 바뀌면 기존 기록이 보이지 않을 수 있음을 안내한다.
- 사용자가 확인할 사항:처음 5명·추가 후 6명·검색 1명·상태 변경·새로고침·닫았다 열기. 실제 하지 않은 브라우저 검사는 미확인이다.
