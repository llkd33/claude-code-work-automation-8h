# Claude가 보는 감시 실행 안내

학생은 시작 프롬프트를 Claude Code 안에 보냅니다. 파일 교체도 Claude에게 맡기고, 실제 보고서는 브라우저에서 확인합니다.

- 제공 프로그램:watch.cjs. 입력 inbox/주간비용.xlsx, 출력 output/auto, 기준50000.
- 내부 실행:node integrations/automation/watch.cjs --input inbox/주간비용.xlsx --output output/auto --interval 5 --checks 12 --threshold 50000
- 이 실습 폴더에서 OS의 별도 보이는 터미널 창을 열어 실행한다. 현재 Claude 대화의 도구를 계속 막고 기다리지 않는다. 외부 창 시작을 못 하면 미확인으로 알려주며 실행 중이라고 주장하지 않는다.
- 시작 전에 첫 입력 사본을 준비한다. 기존 사용자 입력이 있으면 확인받고 보존한다. workbooks 원본은 수정하지 않는다.
- 사용자 안내: 처음 보고서를 확인한 뒤 다음 주 비용표 사본으로 inbox 파일 교체, report.html 새로 열기, 실행 창의 Ctrl+C로 종료. 오류 입력 교체는 기본 실습에 포함하지 않는다. 최대 12회 확인 후 자동 종료된다. 이미 종료됐으면 같은 시작 프롬프트로 현재 입력을 보존하고 다시 켠다. 파일 교체 후 generated 또는 error 로그를 기다린 뒤 결과를 열게 안내한다.
- 실제 로그의 generated/skipped/error만 보고한다. 오류 입력은 정상 결과를 덮어쓰지 않는다.
