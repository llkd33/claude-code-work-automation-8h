# 엑셀 보고서 실행기 · 학생 안내

> 이 폴더는 기존 실행기와 로그인 분석의 참고 소스입니다. 현재 20번 웹 도구 실습은 [웹 제작 기준](../../templates/excel-web-app/01_웹보고서_스펙.md)을 먼저 사용합니다. 아래 exe 안내는 기본 수업 단계가 아닙니다.

1. Claude Code를 켭니다. 로그인 요청이 나오면 제공 계정으로 로그인합니다.
2. 핸드북의 A7 제작 요청 전체를 붙입니다. 다음 주 입력 사본과 OS별 실행 파일을 준비하게 합니다.
3. 실제 ExcelReport.exe 또는 ExcelReport.command가 생겼는지 확인합니다.
4. 실행 파일을 더블클릭합니다. 같은 입력을 중복 분석하지 않습니다.
5. 이번 report.html을 열고12건·1,130,900원인지 봅니다. 분석의 원인·제안은 직접 검토합니다.
6. 실패하면 실제 오류를 오류 도움 요청에 붙입니다. 이전 결과와 인증 파일은 건드리지 않습니다.

입력은 inbox-auth의 Excel 한 개입니다. 다른 파일을 넣을 때는 이전 입력 사본을 보관합니다. 실행 파일만 다른 PC로 옮겨 쓰는 독립 앱은 아닙니다. 준비한 Node·Claude Code·로그인과 인터넷이 필요합니다.

task-spec.md와 소스 파일은 Claude가 보는 제작 자료입니다. 준비·로그인 상태 검사·빌드 명령을 학생이 직접 입력하지 않습니다.
