# 로그인된 Claude Code로 Excel 보고서 만들기

Excel 파일을 넣으면 분석 보고서를 만드는 로컬 프로그램을 만들고 싶어. Claude API 키 대신 이 PC에 로그인된 Claude Code를 사용해 줘. 아래 요구사항과 제공된 소스를 확인해서 Windows 실행기를 만들어 줘. 기존 Excel 계산 코드는 바꾸지 말고, 실제 검증과 아직 확인하지 못한 부분을 구분해 줘.

A7은 제작과 가상 프로세스 테스트까지만 진행해 줘. 실제 분석 호출은 하지 마. 사용자가 실행기를 열어 A8에서 한 번 요청할 거야.

## 입력과 결과
- 입력: 실습 폴더의 `inbox-auth/` 안에 `.xlsx` 파일 한 개. `비용내역` 시트의 전표번호·부서·품목·수량·단가·금액·처리상태 열을 사용한다.
- 결과: `output/auth-report/실행별폴더/`의 `report.html`, `analysis.md`, `summary.json`, `run-state.json`.
- Windows: 실습 폴더의 `ExcelReport.exe`를 더블클릭한다. macOS: 제공 launch.cjs를 실행하는 `ExcelReport.command`를 만들고 더블클릭한다. 작업 폴더를 실습 폴더로 고정하고 실행 결과를 볼 수 있게 창을 유지한다.
- 원본 Excel을 수정하지 않는다. 실행별 폴더를 사용해 이전 성공 결과를 보존한다.

## 인증과 실행 범위
- API 키를 만들지 않는다. 설치된 Claude Code의 `claude auth status --json`에서 `loggedIn: true`, `authMethod: "claude.ai"`를 확인한 뒤 호출한다.
- 인증 파일·토큰을 읽거나 복사하거나 보고서에 기록하지 않는다. 계정 로그인과 갱신은 Claude Code가 처리한다.
- 직접 인증을 바꿀 수 있는 환경변수가 있으면 실행을 중단한다. 다른 인증 방식이면 제공받은 Claude 계정으로 `claude auth login`을 완료한다.
- A8에서 `claude -p`를 한 번 호출하고 최대 2턴, 120초로 제한한다. 수업 기본 모델 `claude-sonnet-5-5`와 `medium` effort를 사용한다. 셸 명령·파일 쓰기·MCP를 허용하지 않는다. `--bare`는 로그인 인증을 건너뛸 수 있어 사용하지 않는다.
- 로컬 프로그램이지만 Claude 분석은 온라인이다. 전달하는 내용은 검증된 건수·합계·부서별 합계·상태별 합계이며, 원본 바이너리와 개별 품목·전표번호는 전달하지 않는다. Claude 계정의 사용량 제한과 기관 정책이 적용된다.
- 기관에서 관리하는 설정은 도구가 우회하지 않는다. 강사는 제공 계정과 실제 PC에서 먼저 실행한다.

## 보고서 작성 기준
1. 숫자는 기존 `integrations/local-report/weekly-report.cjs`로 검사·재계산한다.
2. 원본 검사가 실패하면 Claude를 호출하지 않는다.
3. Claude는 전달받은 집계만 사용해 3줄 요약, 확인할 질문 2개, 다음 행동 2개를 작성한다.
4. 비용이 발생한 원인을 단정하지 않는다. 집계에 없는 원인·효과는 “가설”, 부족한 정보는 “확인 필요”로 표시한다.
5. 최종 HTML의 KPI는 로컬 계산값으로 고정한다. Claude 문장은 HTML로 해석하지 않고 텍스트로 표시한다.
6. 로그인 확인과 응답 수신은 수치·추론의 정확성 보증이 아니다. 사람이 Excel과 합계를 대조하고 제안을 검토한다.

## 완료와 검증
- 성공: 원본 검사 통과, Claude 응답 수신, 응답 형식 확인, 실행 후 원본 해시 일치, 보고서 저장.
- 실패: `run-state.json`에 어느 단계가 실패했는지 기록하고 종료한다. 가짜 분석이나 DEMO 결과를 성공으로 만들지 않는다.
- 자동 테스트는 실제 Excel 파싱과 가상 Claude 프로세스로 검증한다. 실제 로그인·실제 응답과 Windows 실행 검사는 강사 리허설에서 별도 수행한다.
