# AI 기초와 프롬프트 흐름 개선

- 목적: 비개발 초보자가 AI·머신러닝·딥러닝·LLM의 관계와 짧은 역사를 그림으로 이해하고, 프롬프트 원칙을 부담 없이 실제 요청에 적용하게 한다.
- 편집 범위: `실습핸드북.html`의 `#glossary` 및 `#prompt-engineering`, 새 AI 역사 삽화, `docs/change-log.md`, 동기화된 교안·콘텐츠 JSON·배포 패키지.
- 지표: 개념과 연표가 용어 카드 앞에 나오고, 프롬프트 단원에서 좋은 예시 → 세 칸 풀이 → 메타프롬프트 경로가 이어짐. 기존 섹션 ID·프롬프트 ID·메모 키·링크가 보존됨.
- 예산: 한 번 편집 후, 검사에서 발견된 결함만 최대 두 번 보정.
- 품질 관문: 정적 검사와 HTML/링크 검사 통과, 소스와 ZIP 내용 동기화, GitHub Pages 배포 파일이 소스와 일치.
- 기억: 이 파일과 `docs/change-log.md`.
- 중지: 초보자 흐름이 명확하고 배포 검증까지 마친 시점.

## 결과
- 초반 용어 카드 앞에 AI→ML→딥러닝→LLM 관계 도식, 새 설명 삽화, 튜링·다트머스·AlexNet·Transformer·ChatGPT의 공식/원자료 연결 연표를 배치했다. AI가 모두 머신러닝은 아니라는 보충을 넣었다.
- 프롬프트 단원은 먼저 구체적인 회의 메모 예시를 보여주고, 입력·결과·확인을 풀이한 다음, 처음부터 세 칸을 쓰기 어려운 초보자는 AI에게 질문과 짧은 프롬프트 작성부터 맡기는 흐름으로 바꿨다.
- 정적 점검: 28개 단원·54개 프롬프트·32개 메모·24개 이미지·161개 로컬 링크·ZIP 899개 항목 일치. 계산 도구는 변경 없음.
- Chromium 화면 검사: 이미지 정상 로드, 역사 링크 5개, 1280·768·375px에서 넘침과 JS 오류 없음.
- GitHub Pages 배포 `8084b8d`; workflow 38390537619 성공. 공개 핸드북 및 삽화 HTTP 200, 새 문구와 이미지 경로 반영.
- 종료: 요청한 개념·역사·좋은 프롬프트·메타프롬프트 흐름을 추가하고 모든 게이트 통과.
