# 학습 흐름 정리
- 목적: 초보자가 각 핵심 단원에서 개념을 이해하고, 시연을 보고, 직접 해 본 뒤, 원할 때 심화 실습으로 이어가도록 핸드북 안내를 정리한다.
- 범위: `실습핸드북.html`의 단원 소개와 소제목 단계 표지, 동일 문구가 있는 강의용 `교안.md`, 변경 기록. 기존 section id·프롬프트 id·메모 키·자료·계산 동작은 유지한다.
- 지표: 핵심 제작 단원 다수에 개념/시연/실습/심화 단계가 실제 내용에 맞게 표시되고, 목차 앵커·프롬프트 수·메모 동작이 보존된다.
- 예산: 한 번의 내용 편집, 필요한 수정 최대 2회.
- 품질 관문: 28개 단원/54 프롬프트/32 메모 구조 정적 점검, 텍스트 동기화, 반응형 브라우저 확인, GitHub Pages 반영 확인.
- 기억: 이 파일과 `docs/change-log.md`.
- 중지: 단계 설명이 핵심 실습 단원에 적용되고 회귀 검사가 통과한 시점.
