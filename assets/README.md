## HTML에서 사용

핸드북과 같은 상위 폴더 아래 `assets/`를 배포합니다. `img`에는 위 표의 대체 텍스트를 넣고, `figcaption`에는 ‘설명 도식’ 또는 ‘비유 일러스트’라는 표현을 포함합니다. 모바일에서는 확대해 읽을 수 있게 이미지를 링크로 열 수 있도록 권장합니다.

```html
<figure>
  <a href="assets/04-구글데이터-변화감지.png" target="_blank">
    <img src="assets/04-구글데이터-변화감지.png"
         alt="Sheets 읽기 후 이전 성공 지문과 비교합니다. 같으면 종료, 변경이면 대시보드와 Docs를 갱신한 뒤 성공 지문을 저장합니다. 실패 시 이전 지문을 유지합니다."
         loading="lazy" width="1400" height="1100">
  </a>
  <figcaption>설명 도식 · 모든 출력이 성공한 뒤 비교 기준을 저장합니다.</figcaption>
</figure>
```

## 재생성 및 검증

- 도식 원본: `_workspace/visual-assets-render.py`. Python 3 + Pillow 필요. 기본 한국어 폰트는 macOS Apple SD Gothic Neo이고 `VISUAL_KOREAN_FONT`으로 바꿀 수 있습니다. 별도 ttf 사용 시 굵기를 위한 폰트 파일 설정은 추가 조정할 수 있습니다.
- 실행: `/usr/local/bin/python3 _workspace/visual-assets-render.py` (교안 루트에서).
- 생성 도식은 글자 크기 최소 23px, 설명 본문 27px, 핵심 제목 32px입니다. 지정 박스 안의 설명 문자열 폭을 검사합니다.
- 6개 이미지 모두 `view_image`로 열어 한글, 화살표 방향, 겹침, 내용과 강조색을 확인했습니다. 브라우저 내 페이지 배치는 별도 검증 대상입니다.
- 일러스트 생성 프롬프트: `_workspace/visual-assets-image-prompt.md`. built-in `image_gen` 사용, CLI/API 키 경로 미사용.
- 생성 일러스트에는 숫자나 실제 기온을 넣지 않았습니다. 데이터 지문은 암호처럼 보일 필요 없이 ‘다음 실행의 비교 기준’으로 읽도록 표현했습니다.
