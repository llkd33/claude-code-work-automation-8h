# 개념 지도와 내용 검색 · 2026-10-12

## 바뀐 점

- 핸드북 상단·목차에 개념 지도와 내용 검색을 추가했다. 모바일 상단에서도 검색을 연다.
- 개념 39개를 AI 기초·일하는 방법·규칙/도구·실습으로 구분하고 관계 52개에 쉬운 설명을 붙였다.
- 이름/점/연결선 선택, 이웃 개념만 보기, 종류별 필터, 확대·이동·점 끌기, 개념 목록과 키보드 선택을 지원한다.
- 본문과 프롬프트 143개 구간을 검색한다. Gmail/지메일, MCP/엠씨피 같은 표현을 함께 찾는다. 결과를 누르면 해당 문단으로 이동하며 접힌 설명과 기획 탭도 열린다.
- Ctrl+K 또는 ⌘K로 검색을 열고 Enter로 첫 결과를 연다. Esc로 닫는다.
- 검색은 공개 교안만 사용한다. 개인 메모를 읽거나 검색하지 않으며 외부 검색 서비스로 전송하지 않는다.
- 외부 라이브러리·API 없이 SVG/JavaScript로 구현해 ZIP을 풀고 HTML을 열어도 동작한다.

## 검증

실제 Chromium에서 노드 이름 선택, 관계선 선택, 점 끌기, 확대/필터, 검색/키보드/접힌 설명 열기, 375·768px 화면, 메모·체크 저장 유지와 JavaScript 오류 없음을 확인했다. 독립 검수에서 발견한 이름/연결선 클릭 및 모바일 글자 비율 문제를 수정했다. Enter 뒤 검색창이 다시 열리는 동작과 Esc 닫기도 수정해 재검증했다.

기존 28개 절·54개 프롬프트 문장·32개 메모와 모든 이전 앵커·체크 ID를 보존했다. 계산 도구와 Excel은 변경하지 않았다. 실제 Claude 작업 생성·Gmail 인증/전송·Windows 실행은 이번 기능의 검증 범위가 아니다.

내려받은 수강생 ZIP을 풀어 `file://`로 열고 검색→접힌 실습 이동·관계선 클릭·모바일 검색을 확인했다. 이 과정에 HTTP 요청은 없었다. 복사는 웹의 Clipboard API와 오프라인 대체 복사 경로를 각각 확인했다. 로컬 파일에서의 Clipboard API 권한 허용 여부는 브라우저에 따라 다르다. ZIP 4종의 원본 일치 항목 888개와 모든 추가 자산 링크도 검사했다.

## 교안 수정 후 갱신

`python tools/build-knowledge.py`로 현재 HTML에서 검색 색인을 다시 만든다. 이 명령은 제작자용이다. 개념/관계는 이 도구의 nodes/edges에서 편집하고 모든 연결 대상의 존재를 검사한다. `tests/knowledge-browser.cjs`가 주요 브라우저 동작을 확인한다.
